# M1-04ap · 세션 거리·시간 목표 범위와 집계

상태: 구현·검증 완료. S03·S05의 거리/시간 범위와 S06·V2-F11의 세션 입력을 연결한다.

- `durationRange?: { minSeconds, maxSeconds } | null`, `distanceRange?: { minMeters, maxMeters } | null`.
  유한한 0 이상 값·순서가 있는 경계이며 기존 단일값과 같은 기술 상한을 사용한다.
- 범위 객체가 있으면 대응 단일값은 반드시 null이다. 부재/null 범위는 기존 단일값 의미를 유지한다.
  범위의 중간값·하한을 임의의 단일값으로 저장하지 않는다. 과거 버전과 receipt는 필드 부재를 보존한다.
- 입력 방식 전환은 명시적 초안 편집이고 저장은 미리보기·확인이 필요하다. 범위 시간에는 단일값
  resize를 적용하지 않으며, 별도 단일값 전환이 필요하다. 단계 수량은 기존 단일값을 유지한다.
- 계획 집계에 `targets.definitionVersion: planned-targets-v1`을 추가한다. 알려진 단일값과 범위의
  하한·상한을 각각 합산하고 known/missing/range count를 표시한다. 기존 metric은 정확한 단일값만의
  부분 합계라는 의미를 보존한다. 구형 응답은 새로운 범위 집계를 가진 것처럼 취급하지 않는다.
  계획 수량은 JSON에 저장되는 십진수 표현으로 합산한 뒤 한 번만 number로 변환한다. 소수 목표를
  반복 합산한 오차가 거짓 가용 시간 초과나 SQL/JS 합계 차이를 만들지 않도록 한다.
- 시간 제약은 알려진 하한 합부터 초과하면 충돌, 상한만 초과하면 충족 여부 미확인이다.
  미정 세션을 0으로 추정하지 않는다. 운동 불가 날짜의 충돌 판정은 유지한다.
- 실제 거리와 범위의 아래/내부/위를 비교하며 단일 delta는 만들지 않는다. 계획 시간의 측정 정의가
  없으므로 timer/elapsed/moving 실제 시간과의 delta는 계속 계산하지 않는다.
