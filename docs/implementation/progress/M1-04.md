S05 표의 `계획 종류`는 도메인 종류(운동·영양·회복·루틴 등)를 뜻하며 `sport` 종목과
분리한다. 현재 표의 운동 세션 행은 `운동`으로 표시한다. 후속 도메인 통합에서 해당 계획 행을
추가하며, 운동 세션에 영양·회복 값을 임의로 저장하지 않는다.

사용자 명시 완료 상태는 [ai](M1-04ai.md)·[aj](M1-04aj.md), 완료 세션 고정과 기간 이동은
[ak](M1-04ak.md)에 있다. 실제 연결만으로 완료를 추정하지 않는다. 과거 세션/날짜 조작은
`session-operation.ts`에서 거절하고 `session-operation-feedback.tsx`에서 실제 기록 확인·정정 경로를 안내한다.

## S05 계획 종류 결정

[화면 원문](../../.pre/01_product_screen_spec.md)의 S05 “계획 종류”는 `sport`와 같은 종목
값이 아니라 운동·영양·회복·루틴 등 도메인 종류로 표시한다. 도메인 종류와 운동 종목은 서로
다른 필드로 유지하며, 각 도메인 모듈이 자신의 계획 행을 제공할 때 이 열에 매핑한다.

원문 요구를 삭제하거나 출시 gate를 낮추지 않는다. M1-05는 그래프상 M1-04 다음이므로,
코치 구현을 M1-04의 새 선행 조건으로 만들어 순환시키지 않는다. 위 후속 화면까지 완료됐다는
주장 없이 현재 지도 독립 제품 범위와 이후 통합 범위를 구분한다.

이 수용 대조 변경은 문서·참조·DAG·diff 검사 대상이다. 별도 앱 시험을 수행했다고 기록하지 않는다.
독립 Herdr 리뷰의 base/tree와 결과는 문서 커밋 본문에 기록한다.
