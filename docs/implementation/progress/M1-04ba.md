# M1-04ba · 기준 버전별 가변 시나리오 이름

상태: **completed**. 선행 M1-04ar 완료.

기준 계획 버전마다 0..N개 시나리오를 저장한다. A/B/C는 기존 데이터와 빠른 생성 예시일
뿐 고정 슬롯이 아니다. 사용자 이름은 앞뒤 공백을 제거한 1–80자로 받고, 같은 기준 버전의
중복만 거절한다. 기준 버전이 다르면 같은 이름을 쓸 수 있다. 생성·수정은 현재 계획을
바꾸지 않으며, 적용은 별도 확인과 최신 계획 버전·시나리오 수정·완료 상태 검증을 유지한다.

계약·UI와 migration 016을 구현했다. 목록은 URL offset으로 페이지를 이동해 100개 이후의
시나리오에도 접근한다. 시나리오 계약·UI·API 및 계획 표를 포함한 협소 검사 50개와
전체 단위 검사 1,703개, PostgreSQL 통합 검사 181개가 통과했다. lint·typecheck·Prettier와
build 7개 task도 통과했다. 새 이름 생성·기준 버전별 중복 거절의 브라우저 E2E가 통과했고,
Aside 실제 브라우저에서 사용자 지정 이름의 생성·목록·수정 비교 진입 및 현재 계획이
그대로 유지되는 상태를 확인했다.

Herdr 독립 리뷰에서 목록 페이지 이동 후 비교 대상 선택지가 사라질 수 있는 문제를 발견했다.
현재 페이지에 없는 URL 비교 대상도 선택지에 유지하도록 수정하고, 재제출 시 같은 시나리오
ID가 남는 회귀 테스트를 추가했다. 재검토에서 추가 actionable finding이 없었고, 수정 후
계획 시나리오·표 브라우저 E2E 4개가 다시 통과했다.
