# M1-04n · 계획 multi-view 공유 선택·초안 편집

상태: 완료. S05·V2-F09~11의 계획 세션 공유 선택과 명시 저장 흐름을 구현한다.
M1-04j에 의존하며 활동 DB 날짜 보완 M1-04m과 독립적으로 준비했다.

## 범위

- 같은 조회 범위·계획 source를 달력·표·agenda로 표시하고 URL `plannedSession` 선택을 공유한다.
  `plannedView`는 표시 방식이며 기존 `view=stack|split` layout URL을 유지한다.
- 선택 세션 상세에서 날짜를 편집하면 메모리 Zustand 초안만 바뀐다. undo·preview·명시 저장은
  기존 계획 버전 API를 사용한다. 저장본·초안·실제 수행을 분리한다.
- 잘못된 초안을 저장본으로 대체하지 않으며, 범위 밖/없는 선택·lock·Block 범위 오류를 표시한다.
  다른 Block 재배정 또는 실제 활동 날짜/연결 변경을 추정하지 않는다.
- 편집기 DOM과 draft 수명은 보기·responsive 전환보다 위에서 유지한다.
- 달력·표 동시 split 배치, DnD·복제/길이 조절 interaction 확장·고급 표 기능·Orbit·전체 S05 완료는 이 slice가 아니다.
  현재 기본은 agenda이고 달력·표를 명시적으로 전환한다. 기존 layout의 editor/조회 배치는 유지한다.
