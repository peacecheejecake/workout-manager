# M1-04e · 활동 목록 검색·필터 API

상태: 완료. S07의 검색·기간·종목·출처 필터와 정렬을 기존 canonical/overlay 조회에 추가한다.
총건수와 page는 같은 SQL snapshot에서 읽으며 RLS·삭제 suppression을 유지한다.

## 조회 계약

기존 `GET /bff/v1/activities?limit=50&offset=0` 응답 `{items,total}`를 유지한다.
선택 필터는 다음과 같다.

- `from`, `toExclusive`, `timezone`: 세 값을 함께 지정한다. 1~3660개 현지 달력 날짜 범위이며
  종료일은 제외한다. 각 활동의 시작 시각을 지정한 IANA 시간대로 투영한다. 시작 시각이 없으면
  기간 필터 결과에서 제외하고, 기간 필터가 없으면 포함한다. 계획 시간대를 자동 적용하지 않는다.
- `kind`: running/cycling/walking/strength/other/unknown.
- `source`: 현재 실제 지원되는 fit/fixture. 공식 Garmin 수집을 지원하는 값으로 오해하지 않는다.
- `search`: 공백을 정리한 1~200자 제목 검색. 사용자 정정 후 제목에 대해 대소문자 무관한
  문자 그대로의 부분 문자열 검색이다. `%`와 `_`는 wildcard가 아니다. 제목 null은 매치하지 않는다.
- `sort`: id_asc/started_desc/started_asc/distance_desc/distance_asc/title_asc.
  생략 시 기존 ID 오름차순을 유지한다. 측정값/제목/시작 시각 null은 양방향 모두 마지막이며,
  동률은 ID로 정렬한다. 거리 정정의 null과 0을 서로 바꾸지 않는다.
- 여러 필터는 AND로 적용한다. limit 1~~100, offset 0~~10000을 유지하며 total은 필터 적용 후 건수다.
  마지막 page를 넘어간 offset에서도 total을 반환한다. 총건수와 page는 단일 SQL snapshot 결과다.

새 테이블·쓰기·export/backup 형식을 추가하지 않는다. 소유자는 인증된 principal로 정하며
사용자가 쿼리에 athleteId를 주입할 수 없다. 삭제된 정본은 검색·정렬에 노출하지 않는다.

## 남은 범위

목록 UI·수동 기록·태그/주기/품질 필터·대량 동작·상세는 후속 작업이다. S07 전체 완료는 아니다.
이번 API는 날짜가 불명확한 활동을 임의의 날짜에 배정하거나 완료된 수행으로 판정하지 않는다.
지도 coverage·OS IME·실기기·공식 Garmin의 완료 조건과 저장소 규칙은 유지한다.
