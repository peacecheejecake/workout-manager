# M1-04aq · 활동 로컬 태그·일괄 편집·필터

상태: 구현·검증 완료. S07의 로컬 태그 일괄 동작을 실제 API·DB와 연결한다.

- 태그는 `overlay.tags?: string[]`에만 저장한다. 부재는 이전 기록 보존, 빈 배열은 명시적 비움이다.
  원본·유효 측정값·사용자 RPE/계획 연결 보고와 분리한다.
- 태그 최대 20개, 각 1–40 UTF-16 단위의 기술 상한이다. 앞뒤 공백 제거·NFC 정규화 후
  빈 값·제어/비표시 제어 문자·중복을 거부한다. 대소문자는 구분하고 내부 공백·문장부호는 보존한다.
- 기존 overlay 명령의 revision·사유·멱등성·이력·outbox를 재사용한다. tags 생략 시 이전 집합을
  보존하며 태그 수정도 기존 reason 기반 `corrected` 필터의 로컬 수정에 포함된다.
- 한 태그를 선택 활동 최대 100개에 추가/제거한다. 항목별 조회에서 revision과 최종 태그 집합을
  확인한 뒤 명시 승인한다. 무변경·실패·충돌·불명 결과를 구분하고 전체 원자 성공을 주장하지 않는다.
- URL `tag`는 정규화된 태그의 대소문자를 구분하는 정확 일치 필터이며 다른 조건과 AND로 결합한다.
- 새 선택 요약 내보내기는 version 2이다. 태그 없는 version 1 파일은 계속 읽을 수 있다.
  태그를 포함하는 파일에 version 1을 붙이지 않는다. 기존 계정 export의 overlay 이력도 유지한다.
