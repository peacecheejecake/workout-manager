# M1-04ao · 세션 참석 잠금·삭제 보호

상태: 완료. S06·V2-F11의 참석 잠금을 추가했다.

원문은 참석 잠금을 열거하지만 구체적인 보호 동작을 정의하지 않았다. 후속 선택 질문에
별도 답변이 없어 권장안을 기본으로 삼는다고 알리고 **세션 삭제만 보호**하는 의미로 구현한다.
일정과 강도는 기존 개별 잠금 및 사용자 완료 보고의 보호를 따른다.

- `locks.attendance?: boolean`은 기존 버전의 필드 부재를 보존하며 null을 허용하지 않는다.
- 저장된 참석 잠금이 true이면 세션 삭제를 거절한다. 해제를 별도 버전으로 저장한 뒤 삭제한다.
- 참석 잠금만 켜져 있으면 날짜·소속 Block·시각·시간대·내용 수정이 가능하다.
- 기존 date/time/intensity 잠금의 삭제 보호를 유지한다. 완료 보고를 변경하지 않는다.
- 복제본은 새 ID를 가진 독립 초안이며 참석 잠금도 해제한다. 원본은 유지한다.
- 잠금 상태는 참석 여부·실제 활동·완료의 증거가 아니다.
