# M1-04ax · 세션별 저장본·초안 변경 표시

상태: 구현·검증 완료. S05 변경 표시를 표·달력·agenda에 연결한다.

- 저장 모드의 `저장본`, 초안의 `저장본과 동일`·`수정된 초안`·`새 세션`을 제목 옆에 표시한다.
  색상과 별도로 텍스트를 제공하고 기존 선택 버튼의 접근성 이름을 유지한다.
- 편집 시작 시 저장본과 현재 세션 전체 값·상속하는 계획 시간대를 비교한다. 객체 key 순서는
  무시하지만 배열 순서, 필드 부재, null, 0, 목표·단계·잠금은 구분한다.
- 계획 제목·기간 메타데이터만 바꾸면 세션 변경으로 표시하지 않는다. 화면에 비교 범위를 안내하고
  전체 변경·삭제는 기존 미리보기에서 확인한다. 삭제된 세션의 가상 행을 만들지 않는다.
- 새 ID의 복제 세션은 새 세션으로 표시한다. 실행 취소·초안 폐기·명시적 저장 후 표시를 현재 상태에서
  다시 계산하며 별도 상태 저장소나 쓰기 API를 만들지 않는다. 실제·완료 보고는 독립 상태를 유지한다.
- 기존 버전 비교의 깊은 값 비교 함수를 추출하여 동일한 비교 의미를 재사용한다.
  아직 없는 AI/승인 상태를 만들어 표시하지 않는다.
