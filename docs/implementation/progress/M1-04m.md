# M1-04m · 활동 조회 달력 경계 보완

상태: 완료. 기존 가져오기 계약이 허용하는 ISO year0000 기록 때문에 전체 목록과
대시보드 조회가 실패하는 결함을 보완한다.

## 범위

- 정렬·날짜 필터·집계용 SQL 시각만 PostgreSQL의 같은 천문학적 연도인 1 BC로 투영한다.
  원본·정정 JSON의 시각 문자열, timezone·offset·윤일·null을 보존한다.
- 목록의 안정 정렬·null-last·paging, 시간대별 AD 경계 날짜 조건과 dashboard 조회를 검증한다.
- 수동 입력의 날짜 제한, 활동 context의 `unsupported_calendar`, 계약·규칙은 변경하지 않는다.
- 소유권/RLS, immutable source/revision·suppression, 지도·OS IME·실기기·공식 Garmin gate를 유지한다.
