# M1-04l · 명시적 계획 Block 활동 필터

상태: 완료. S07·V2-F12의 주기 필터 중 명시적으로 연결한 Block 조회를 구현한다.

## 조회 의미

- `linkedPlanVersionId`와 `linkedBlockId`를 함께 지정한다. 해당 사용자가 소유한 불변 계획
  버전의 Block 소속 세션에 명시적으로 연결한 활동만 포함한다.
- 실제 수행 날짜·종목으로 링크를 추측하지 않는다. 연결 Block 범위 밖 또는 시작 시각 미확인도
  명시 연결이 맞으면 포함하며, 별도 날짜 필터는 실제 시작 시각 조건과 AND로 결합한다.
- 과거 계획 연결을 현재 head로 바꾸지 않는다. 없는 Block·다른 사용자 버전은 빈 결과이며
  삭제된 활동은 제외한다. 목록·총건수는 기존 단일 SQL snapshot에서 계산한다.
- UI는 현재 계획의 Block 선택, 연결 context에서 과거 버전도 포함한 필터 URL 이동,
  조건 표시·해제·기존 필터/선택/paging을 연결한다.
- 품질 등급·생리학적 점수·로컬 태그 또는 전체 주기 탐색은 이 slice가 아니다.
