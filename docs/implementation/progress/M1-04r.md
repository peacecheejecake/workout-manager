# M1-04r · 세션 복제 초안 선택·경계 보완

상태: 구현·검증 완료. 기존 복제 버튼의 선택 누락과 계약 경계 문제를 보완한다.

## 범위

- 복제 성공 시 새 초안 세션을 선택하고 달력·표·상세·편집기를 같은 ID로 연결한다.
- 제목 200자·세션 1000개 제한과 ID 중복을 검증한다. 복제할 수 없으면 초안을 변경하지 않는다.
- 새 세션·단계 ID를 생성하고 원본 객체·값·잠금을 유지한다. 복제본은 기존 동작대로 잠금을
  해제한 새 계획 초안이며 사용자에게 이 의미를 설명한다. 실제 활동·수행 연결을 만들지 않는다.
- undo 한 번으로 취소한다. 사라진 복제본 선택은 해제한다. preview와 명시 승인 전 저장하지 않는다.
- DnD·resize·완료 활동 정정 경로와 전체 S05 완료는 별도 작업이다.
