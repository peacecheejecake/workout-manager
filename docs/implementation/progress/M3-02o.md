# M3-02o · HealthKit 계정별 등록 통합·안전 배포 준비

상태: **진행 중**. 선행 k/l/m/n의 로컬 수용을 바탕으로 기존 자료 감사·서버 선배포·구형 앱 차단·safe rollback 준비를 병렬 진행한다. 운영 수용과 제품 실기기 증거는 별도다.

## 작업 소유권

- API/persistence 담당: 개인정보·UUID를 반출하지 않는 기존 raw/receipt 감사와 실제 합성 PostgreSQL 통합 검증. 자동 claim backfill이나 기존 자료 삭제를 하지 않는다.
- 웹 담당: 웹/native bridge lifetime 통합의 남은 concrete risk 검사, 구형 host·계정 전환·동의 철회·응답 손실과 배포 절차 준비.
- root: public export·공통 계약·graph/진행 기록, 결과 통합, 전체 phase gates 및 context-less 독립 phase 검토.

## 기준과 미실행

선행 n은 `dcca9879`로 phase/m3-02에 커밋됐다. l의 역사 v1 receipt 미상 membership은 해제를 차단하며 자동 귀속 복구하지 않는다. 서버의 구형 runtime/DB 상태는 운영 배포 수용으로 세지 않는다. 실제 기존 자료 감사·운영 원장 삭제·이미지 rollback·백업 복원·제품 HTTPS 등록·개인 HealthKit·UIKit/VoiceOver·실기기 수용은 **not_executed**다. 합성 fixture나 SDK compile로 이를 통과 처리하지 않는다.

## 개별 해제 제품 연결

기존 l은 고정 POST/GET과 cleanup worker를 제공하지만 제품 native/WebView 소비자가 없어 이를 o에서 연결한다. 등록 관리 화면에서 단일 대상의 관련 소유 기록 삭제를 명시 확인하며, HealthKit 원본을 삭제하지 않는다. 원본 요약은 registered UUID에 한정한 native-only 표시 page의 제한 조회로 제공하고 불가하면 미확인 fallback을 표시한다. `pending_cleanup`은 release가 아니며 `RECEIPT_MEMBERSHIP_REQUIRED`는 `legacy_blocked`로 표시한다.

선택과 별도의 optional `healthkit.workouts.management` capability와 `manage`/`managementStatus`/`cancelManagement` 계약을 추가했다. 무작위 managementId는 native UI lifetime handle이며 sample/claim/operationId가 아니다. WebView에는 유한 상태와 0~1 선택·결과 건수, 미확인 null을 구분하는 등록 건수만 보낸다. 이전 계정 handle 취소가 새 화면에 영향을 주지 않아야 한다.

## 기존 자료 감사의 로컬 수용

`auditHealthKitRegistration`은 5개 관련 table의 session_user 소유권을 확인하고 `REPEATABLE READ READ ONLY`, statement 5초/lock 3초 timeout과 `row_security=off`로 tenant 부분 집계를 거부한다. 원문·UUID·계정 값은 반환하지 않고 최대 1,000,000건/항목의 scalar count와 overflow 표식만 반환한다. 역사 receipt의 미상 membership은 별도 집계하며 `historicalOwnershipProven:false`를 유지한다. raw·known receipt·두 자료의 합친 계정 중복을 각각 집계한다. 자동 귀속 복원·삭제·purge는 없다.

- 실제 격리 PostgreSQL **3파일·19/19**: 감사 5·개별 해제 10·rollback fence 4. 빈 DB의 미확인 역사, 합성 중복/legacy/tombstone/동의 revision, 읽기 전후 원본 fingerprint 불변, bounded overflow, runtime owner 거부, plain owner FORCE RLS 거부와 rollback 후 연결 재사용을 검증했다. 기존 v1 unknown 해제 원자 거절 및 구형 receipt fence를 보존했다.
