# M1-04at · 체크인 자기보고 관측 추세

상태: 구현·검증 완료. 원문 S12 화면 목록 및 §8의 추세·자기보고/null 구분을 구현한다.

- 조회 기간은 기존 목록과 같은 각 기록의 현지 날짜 1~90일이다. 추세는 독립적인
  `trendOffset` URL과 100개 페이지를 사용한다. 목록 20개 페이지를 전체 기간으로 표시하지 않는다.
- 기존 API의 한 SQL snapshot에서 items·total·collectionRevision을 받는다. 페이지를 합산하거나
  다른 revision의 관측을 혼합하지 않는다. 중복 ID·기간 밖 값·건수 불일치는 표시하지 않는다.
- 피로와 불편감을 분리한 0~10 원본 관측점이다. x축은 관측 시각 UTC이며 각 페이지의 시각 범위를 표시한다.
  페이지 안에서 시각과 안정적인 ID 순으로 정렬한다. 같은 시각의 복수 기록을 보존하고 겹친 점은 표에서 확인한다.
- null은 점을 만들지 않으며 0은 알려진 보고 값이다. 원본 표는 시각·시간대·현지 날짜·값·revision을 보존한다.
  평균·보간·회복 점수·의학적 해석을 만들지 않는다.
- 전체/부분 조회와 현재·전체 건수를 표시한다. 부분 페이지의 미보고 건수를 전체 기간으로 해석하지 않는다.
  기존 API offset 상한 10,000에 도달하면 더 좁은 기간으로 남은 기록을 확인하도록 안내한다.
- 기간 변경은 두 페이지를 초기화한다. 페이지·상세 이동은 작성 초안을 유지하고 상세에 focus를 옮긴다.
  정정·삭제 뒤 목록과 추세를 함께 갱신하고, 실패·재조회 중에는 이전 추세를 최신처럼 표시하지 않는다.
  사용자/세션별 QueryClient 수명과 취소를 유지한다.
