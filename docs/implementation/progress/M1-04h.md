# M1-04h · 수동 활동 입력·정정 UI

상태: 완료. S08·V2-F12·V2-A31. M1-04g API 위에 수동 입력·미리보기·명시 저장과 정정을 연결했다.

## 구현

- `/activities/new`, `/activities/:id/edit`의 thin Next shell에서 공통 `ActivityEditor`를 사용한다.
  목록에서 수동 입력으로 이동하고, 선택 상세에서 수동/가져온 활동을 정정한다. 잘못된 ID는 404다.
- 제목·종목·시작 시각/시간대·거리·시간/정의·RPE·메모·계획 연결·정정 사유를 편집한다.
  시각은 시간차를 포함한 ISO 입력이며 현지 시간을 임의 변환하지 않는다. 빈 값은 null로 유지하고
  관측 0과 구분한다. 생성에는 제목·시각·시간대가 필요하며 정정은 기존 미확인 값을 유지할 수 있다.
- 계획 선택은 실제 조회한 snapshot의 세션만 허용한다. 기존 과거 버전 연결은 유지한다.
  계획 조회 실패를 연결 해제로 해석하지 않는다. 계획 연결·미리보기는 실제 활동을 생성하지 않는다.
- Zustand store는 사용자/세션별 메모리 초안을 소유한다. TanStack Query가 조회 cache를 소유하며
  레이아웃 변경으로 초안을 재생성하지 않는다. 건강 정보를 local/session storage에 저장하지 않는다.
- 미리보기에서 입력을 고정하고 명시 확인 후 저장한다. 응답이 유실되면 동일 payload/key로만
  재시도하며 편집·폐기·대상 전환을 잠근다. 중복 확인은 요청을 중복 실행하지 않는다.
- 확정 400 거절은 작성 내용을 유지한 채 입력으로 돌아간다. 409는 기준/최신/작성값을 비교하고
  명시적으로 최신 revision으로 재검토한 뒤 새 확인을 받는다. 미확인 실패를 저장 성공으로 표시하지 않는다.
- 저장 응답과 저장 후 현재 GET을 분리한다. GET 실패/삭제는 저장 실패로 오해하지 않으며, 최신 확인 없이
  오래된 revision으로 편집을 다시 시작하지 않는다. 성공한 GET은 해당 record cache를 갱신한다.
- IME Enter로 저장하지 않는다. 초안을 버리는 명시 확인과 beforeunload 경고를 제공한다.
  계정 전환/unmount는 요청을 중단하고 초안·기준·고정 명령과 private cache를 제거한다.
