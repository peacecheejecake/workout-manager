- **로컬 파일 preview는 basemap 없이 그린다.** Next `apps/web/app/activities/track-preview/track-preview-page.tsx`와 Vite
  `apps/mobile-web/src/track-preview-page.tsx`는 `basemap={null}`을 넘긴다. Next 쪽 주석은 "M2-01b renders the recording with no

  basemap 요구가 없고, 시험도 화면도 상태를 "배경 지도 없이 경로를 표시했습니다."로 정직하게 알린다. 그래서 결함으로 판정하지
