# M1-03 · Import·Activity

기준일: 2026-09-16. 상태: 구현·검증 완료. S08–S12/FUT-02의 수동 FIT·활동 정본 기반 범위다.

## 구현

- Python `export-activity`가 CRC/크기 검증된 FIT의 session 요약을 schemaVersion 1 JSON으로 변환한다.
  최대 100개 session, 파일 hash+session index 식별자로 같은 파일의 이름 변경에도 중복을 막는다.
- `start_time`만 시작 시각으로 사용한다. timer/elapsed 측정 정의와 null/0을 보존하며 timezone은
  명시 입력만 받는다. record/GPS·기계 시간대로 누락을 추정하지 않는다. 원본은 변경하지 않고 기존 출력도 덮어쓰지 않는다.
- `/activities`에서 JSON 미리보기 후 명시적으로 가져온다. 인증 tenant의 source revision,
  canonical, immutable overlay revision, receipt, suppression을 분리한다.
- 같은 source의 revision·hash/payload 충돌 검사, 이전 revision 무시, 멱등 재시도,
  원본 갱신 후 정정 보존, 로컬 삭제 후 재수입 억제를 transaction/outbox와 함께 처리한다.
- 목록·출처·정정 사유·거리 정정·삭제 확인을 제공한다. 시간 정정 API는 durationKind를 함께 고정하여
  원본이 timer에서 elapsed로 바뀌어도 정정값의 뜻을 보존한다. 혼합 시간 정의는 총합 대신 정의별로 집계한다.
- 부분 import 실패·불확실한 저장 결과·409에서도 안정된 재시도 명령과 초안을 보존한다.
  삭제는 확인창을 연 revision을 고정하며 갱신·충돌 시 새 확인이 필요하다.

## 검증·리뷰

- 통합된 전체 TypeScript unit/component 318개, 실제 PostgreSQL 38개, Python 34개 통과.
  생성물·Prettier·ESLint·typecheck·production build와 Playwright 회귀를 실행했다.
- PostgreSQL: 동시 dedup, tenant 격리, source revision·overlay audit, 삭제 suppression,
  outbox rollback/replay, mixed duration 집계와 원본 변경 후 정정 정의 보존.
- 실제 parser/exporter가 만든 synthetic golden JSON 일치를 pytest로 검증한다.
  같은 JSON을 production Next/Fastify/임시 DB/로컬 OIDC E2E로 가져와 정정·재수입·삭제·억제를 확인한다.
- Aside 실제 브라우저: JSON 선택·미리보기·가져오기, 0초/거리 미확인 표시, 거리 0 정정과 집계 반영 확인.
  최종 삭제 경쟁 조건은 component/E2E 회귀로 검증했다. 개인 FIT/GPS는 사용하지 않았다.
- Herdr `workout-contract-review` (`wD:p6`)의 시간 정의 변경·삭제 revision 지적을 수정했다.
  재리뷰 findings 없음. 최종 base HEAD/staged tree는 커밋 메시지에 기록한다.

## 실행·한계

```bash
uv run workout-manager export-activity /path/to/activity.fit --output /path/to/activity.json --timezone Asia/Seoul
pnpm build
pnpm test:identity
```

로그인 후 `/activities`에서 JSON을 선택한다. `--timezone` 생략 시 미확인으로 남는다.
FIT session timestamp와 start_time은 별개라는 [Garmin 안내](https://forums.garmin.com/developer/fit-sdk/b/news-announcements/posts/important-fit-activity-file-message-change)를 따른다.

이 단계는 동기식 수동 가져오기와 durable outbox 기반이다. 장기 worker 배포·공식 Garmin 자동 sync,
binary 원본/media 저장, 서로 다른 provider의 fuzzy dedup, 상세 map/chart는 후속 작업이다.
정확한 source lineage만 합치며 비슷한 활동을 임의 병합하지 않는다. 로컬 삭제는 source/audit와
suppression을 보존하므로 계정 전체 개인정보 삭제·내보내기(M1-06a)와 구분한다.
