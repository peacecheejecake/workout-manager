# M0-05 · API·PostgreSQL 기반

기준일: 2026-09-16. 상태: **완료** — 기반 구현·실DB 시험·독립 peer review 완료.

Codex native agent가 API와 persistence를 파일 소유권으로 분리해 병렬 구현했다. Root가 manifest,
의존성·CI·실행 설정·검증·커밋을 통합했다. 기존 규칙이나 설계 원본을 수정하지 않았다.

## 구현

- Fastify `createApi` factory: 인증/동의 port 주입, `/health`, `/bff/v1/session`, consent GET/PUT.
- 인증 adapter의 principal에서 athlete scope 도출. 요청의 tenant/athlete 필드는 허용하지 않는다.
- Cookie mutation은 exact Origin과 session CSRF token 검사. 크기 제한, no-store, 안전한 오류·상관 ID 로그.
- PostgreSQL 15 + `pg`, parameterized SQL migration 및 tenant RLS. Runtime은 테이블 소유자·superuser·BYPASSRLS 금지.
- Transaction-local tenant 설정과 타임아웃, 실패 rollback, 완료 후 transaction handle 사용 거부.
- Consent revision CAS, absent-head 경쟁, idempotency receipt와 outbox를 같은 transaction에 기록.
- Outbox deduplication, SKIP LOCKED lease, 재시도, 만료 및 lease token fencing.
- `pnpm test:integration`은 실제 DB 테스트를 실행한다. URL을 지정하지 않으면 새 임시 로컬 PostgreSQL을
  private Unix socket으로 생성하고 시험 종료 후 제거한다. CI는 별도 PostgreSQL service와 제한 role 사용.

## 검증·리뷰

- API Fastify inject 18개 통과, 실제 PostgreSQL integration 14개 통과(API 포함).
- Root 전체 format/lint/typecheck/Vitest 205개 통과(병렬 M0-03 포함).
- Herdr `workout-contract-review`, split pane `wD:p6`: P2 1건 수정 후 재리뷰 findings 없음.
- 수정: SQL 오류를 callback이 catch하면 PostgreSQL COMMIT이 ROLLBACK을 반환할 수 있다.
  응답 command가 실제 COMMIT인지 검사해 거짓 성공을 거부하고 consent/outbox rollback을 실DB 시험했다.
- 기준 HEAD와 검토한 staged tree는 해당 task 커밋 메시지에 기록한다.
- GitHub Actions workflow 작성, 원격 CI 실행은 미수행.

## 범위와 실행

```bash
pnpm test:integration
# PostgreSQL 경로가 자동 탐지되지 않으면 PG_BIN 지정
PG_BIN=/path/to/postgresql/bin pnpm test:integration
```

`TEST_DATABASE_ADMIN_URL`과 `TEST_DATABASE_URL`을 설정하면 그 DB에서 migration과 테스트를 실행하므로
별도 폐기 가능한 테스트 DB만 지정한다. 관리자와 runtime 연결은 분리하며 운영 DB에 실행하지 않는다.

API는 주입 가능한 factory이며 기본 로그인·실행 서버·배포 인증 adapter를 제공하지 않는다.
서버 package의 build 명령은 TypeScript 검증이고 실행 bundle을 생성하지 않는다. M1-01에서 실제
인증 공급자/세션 저장소와 bootstrap을 연결한다. Worker 실행기, 전체 삭제/철회 전파, 제품 승인 engine,
provider sync와 OpenAPI/client 생성은 아직 구현하지 않았다. Shell의 가상 활동과 이 API는 연결되지 않았다.
