# M1-04y · 활동 구간·시계열 상세 workbench

상태: 완료. M1-04x의 실제 source revision 상세 API를 활동 화면에 연결했다.

## 범위

- context와 상세를 병렬 조회하고 활동 ID·canonical revision·source identity가 일치할 때만
  결합 표시한다. 실패·404·정상 상세 없음·revision 불일치를 구분하고 명시 재조회로 복구한다.
- 원본 거리·심박 차트, record/lap 표, 상세 출처를 제공한다. 시각은 원본 UTC 기준이며
  사용자가 정정한 활동 시작 시각으로 원본 관측을 이동하지 않는다.
- 활동·source revision·계정 수명에 한정한 Zustand 선택 상태만 공유한다.
  서버 DTO는 Query cache에 두고 건강 데이터/선택을 영속 저장하지 않는다.
- null/0·중복/역행 timestamp를 보존하고 해당 경계의 선을 끊는다. 누락을 보간하거나
  거리를 속도/페이스로 추정하지 않는다. 랩 시간 범위는 시작+elapsed로만 계산한다.
- 전체 관측은 유지하고 차트는 500개, 표는 20개 단위로 페이지를 나눈다.
  선택 범위와 원본 index를 명시하며 키보드·터치 대안을 제공한다.
- GPS·지도·미디어는 이 slice에 포함하지 않는다. 현재 상세 형식에 GPS가 없다는 사실을
  실제 활동에서 GPS를 관측하지 않았다는 결론으로 확대하지 않는다. S09 전체 완료가 아니다.
