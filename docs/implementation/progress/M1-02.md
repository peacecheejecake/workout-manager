# M1-02 · Plan·Planner

기준일: 2026-09-16. 상태: 구현·검증 완료. S04–S06/FUT-01의 계획 버전·projection·draft 기반 범위다.

## 구현

- `/account`의 훈련 계획 링크에서 `/planner`로 진입한다. 표준 OIDC 세션으로 조회·저장하며,
  tenant는 서버 인증으로 결정한다. 세션 바인딩·Origin·CSRF·멱등 키를 검증한다.
- Season→Wave→Phase→Block과 계획 Session/step의 runtime 계약, 부모·날짜·시간대·중복 ID 검증.
  Block의 기본 10일과 달력 주는 별개이며 기간 길이는 수정할 수 있다. 시간·거리 미정과 0을 구분한다.
- 수동 초안→변경 전후 미리보기→명시 확인으로 immutable PlanVersion을 저장한다.
  head/history/receipt/outbox는 한 transaction에 반영한다. 이전 잠금 해제도 별도 버전 저장이 필요하다.
- URL은 calendar/rolling/period 조회와 배치를, Zustand는 세션 범위 draft·undo·preview를 소유한다.
  TanStack Query가 서버 정본을 조회한다. resize로 draft·focus가 사라지지 않는다.
- 저장 충돌은 초안을 보존하고 최신 head 재검토를 요구한다. 과거 멱등 receipt를 현재 head로 표시하지 않는다.
  일시적인 세션 재조회 실패는 유효기간 내 초안을 유지하되 요청을 막는다. 만료·계정 교체는 개인 상태를 제거한다.
- 한국어 필드별 검증 안내, 키보드 가능한 기간/세션 추가·수정·복제·삭제, 날짜/시간/강도 잠금.

## 검증·리뷰

- Prettier·ESLint·typecheck·생성물 검사, 계약·draft·component·API·세션 수명 회귀 시험.
- 실제 PostgreSQL 계획 시험 6개: 동시 head 경쟁, receipt 재시도, tenant 격리,
  immutable 이력, outbox 실패 rollback, 잠금 해제 후 변경.
- Production Next/Fastify/임시 PostgreSQL/로컬 OIDC Playwright: 계획 생성·미리보기·버전 1 저장,
  reload 후 시간 미정→0 변경·버전 2 저장, 320/768/1280px에서 메모·focus·reflow 확인.
- Aside 실제 브라우저: Alice 로그인, 기간 4단계와 세션 생성, 한글 메모 입력, 미리보기와 버전 저장 확인.
  이는 OS IME 조합 이벤트 시험을 대신하지 않는다. 최종 경쟁 조건 수정은 component/E2E로 검증했다.
- Herdr `workout-contract-review` (`wD:p6`) 독립 리뷰의 인증 실패 draft 소실과 과거 receipt 표시 지적을 수정했다.
  수정 재리뷰 findings 없음. 각 커밋 메시지에 최종 검토 base HEAD와 staged tree를 기록한다.
