# M1-05j2 · 불변 후보 원장·digest·수명주기

상태: **completed**. 선행 M1-05j1 완료. 검증된 훈련 후보를 tenant별
Decision/Proposal/Candidate 불변 원장에 저장하고, 후보 내용과 분기 ID를 묶은
SHA-256 digest를 서버에서 생성한다. 생성 transaction은 사용자 단위 잠금 아래
고정 근거·현재 core-v2 의존성·AI 동의·대화 revision·정책·계획·완료 보고를 재검사한다.
동일 요청의 병렬 재전송은 같은 후보를 반환하고, 다른 본문의 동일 키는 충돌로 거절한다.
멱등 receipt에는 요청 본문 대신 비교용 SHA-256 해시와 후보 ID만 남긴다.
실행 상태는 같은 transaction에서 `validated_final`로 옮기지만 계획 head는 변경하지 않는다.

Migration 018은 세 원장에 tenant RLS, 참조 무결성, 본문 불변성을 적용한다. 근거 원본
삭제나 AI 동의 철회 시 세 본문과 digest를 회수하고, 계정 삭제 시 행을 제거한다.
내보내기 v9는 현재 동의·근거가 유효할 때만 본문을 담고 v8 파서 호환성을 유지한다.
복원 드릴은 최신 외부 철회·삭제 원장 재생 뒤 본문·digest가 되살아나지 않는지 확인한다.

현재 fixture의 미검증 요약을 자동 후보로 승격하지 않는다. 서버 검증 API·구조화
fixture E2E는 M1-05j3, 명시 승인 transaction과 새 PlanVersion은 M1-05k 범위다.

전체 격리 PostgreSQL 통합 테스트와 합성 backup/restore 드릴 34개 검사를 통과했다.
전체 workspace 검사·API E2E 및 Herdr split-pane 리뷰의 정확한 base/tree identity는
task 커밋 본문에 기록한다.
