# M1-04t · Planner 날짜 이동·시간 길이 조절

상태: 구현·검증 완료. V2-F10 / V2-A13–16 및 S05의 초안 상호작용.

## 범위

- 달력 날짜 이동 drag/drop과 move-to-date 입력, 길이 조절과 숫자 입력을 같은 초안 검증에 연결한다.
- 시작 시각·거리·단계·실제 기록은 추정하거나 변경하지 않는다. 시간 미정 세션은 날짜만 drag 이동하며
  길이는 숫자로 명시 입력한다. Block·잠금·전체 초안을 검증하고 변경 요약과 단일 undo를 제공한다.
- 제스처 취소·Escape·반응형 전환은 초안을 변경하지 않는다. 실제 기록은 별도 정정 경로다.
- 미리보기와 명시 저장 전 쓰기 없음, 통신 실패/버전 충돌 시 초안 보존을 검증한다.
- 지도·OS IME·실기기·공식 Garmin gate와 규칙은 변경하지 않는다.

## 검증

- 날짜와 길이 조작을 같은 순수 초안 명령으로 검증하고, 변경한 명령만 한 번의 undo에 기록한다.
  계획 시간대의 현재 날짜를 조작 시점에 다시 읽는다. 시간 미정과 0초를 구분한다.
- 현재 및 저장된 날짜 잠금은 날짜와 Block을 함께 보호한다. 길이는 intensity 잠금을 따른다.
  잠금 해제와 보호된 변경을 한 번에 저장할 수 없으며 서버에서도 이를 검증한다.
- `@dnd-kit/react` 0.5.0의 별도 손잡이만 drag를 시작한다. browser adapter는 지연 로드하며
  지원 불가/로드 실패 시 날짜·Block 입력 대안을 유지한다. resize/unmount/Escape는 제스처를 취소한다.
