# G1 · 러닝 core 통합 개발 gate

상태: **completed** (2026-09-18). [M1-04](M1-04.md)의 지도 독립 오늘·계획·활동·
체크인, [M1-05m](M1-05m.md)의 training-only 근거→결정론 후보→명시 승인,
[M1-06a](M1-06a.md)의 운영·내보내기·계정 삭제를 내부 개발 경로로 합류했다.
실제 OIDC·BFF·격리 PostgreSQL·브라우저에서 합성 수동 활동부터 새 PlanVersion까지
연결했고, 승인 전 계획 불변·저장 후 단일 버전 증가를 확인했다.

현재 gate에서 다시 실행한 검증:

- OIDC/실DB Playwright **15/15**: 로그인·계정 전환 격리, 운영 export/삭제,
  수동 계획·활동, 오늘 대시보드와 tenant 격리, 근거 캡처·철회, 코칭 실행·후보·승인,
  합성 활동부터 승인까지의 연결 시나리오.
- 격리 PostgreSQL 통합 **226/226**: RLS·삭제·철회·outbox, worker 실패·재시도,
  승인 멱등·동시성·rollback을 포함한다.
- 생성물·Prettier·ESLint·20개 패키지 및 루트 TypeScript, 118개 노드 DAG의
  참조·순환·완료 선행 조건과 evidence 경로 검사 통과. 런타임 코드는 이 gate에서
  변경하지 않았다.

이 gate는 합성 OIDC 계정·수동/FIT·비프로덕션 `synthetic-v1` 코치 fixture를
사용하는 **내부 개발 수용**이다. 공식 Garmin 권한·실제 수집, 실제 LLM의 판단 품질,
생리학적 유효성, 지도 coverage, Native 실기기, 운영 배포 및 Web MVP 출시는
각 외부·후속 gate에 남는다. 전체 identity suite 재실행 대신 위 15개 핵심 경로와
기존 M1-04 전체 수용 기록을 대조했다.

Herdr split-pane 리뷰의 정확한 base/tree와 결과는 gate 커밋 본문에 기록한다.
