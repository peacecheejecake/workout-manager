# M1-04j · Planner 실제 활동 레이어

상태: 완료. M1-02와 M1-04i 이후의 지도 독립 제품 구현이다.

## 범위

- 기존 일별 계획 agenda 옆에 인증된 실제 활동 목록을 연결한다. 편집 중 초안과 실제 기록을 별도로 유지한다.
- 실제 조회는 저장된 계획의 시간대와 URL의 rolling/calendar 범위 또는 저장된 period 범위를 사용한다.
  초안의 시간대·기간 수정으로 실제 조회 기준을 바꾸지 않는다. 저장된 계획·기간이 없으면 조회 불가를 표시한다.
- 한 페이지 50개, URL page와 bounded offset, 기간 전체 개수/현재 페이지 수를 표시한다.
  페이지별 조회를 기간 전체의 일관된 합계로 해석하지 않는다.
- 실제 활동의 명시 계획 연결과 미연결을 구분한다. 같은 날짜·종목으로 링크나 이행률을 추측하지 않는다.
- 활동 상세는 새 탭으로 열어 기존 플래너의 메모리 초안을 유지한다.
- 전체 달력 grid·table·계획/실제 공통 selection·drag/undo는 이 slice의 완료 범위가 아니다.
