# M1-04ak · 기간 날짜 이동 영향 확인

상태: 구현·검증 완료. S04의 같은 길이 기간 이동을 명시 검토 후 초안에 적용한다.

- 선택 기간만 이동 또는 자식 기간·세션을 함께 이동할지 직접 선택한다.
- 완료 확인·날짜 잠금 세션의 날짜를 고정한다. 이동 뒤 소속 Block 밖이면 전체 적용을 거절한다.
- parent 포함·sibling 비겹침·자식 포함·세션 Block 포함을 검증하며 부분 기간도 예외가 아니다.
- 날짜별 운동 불가·가용 시간은 원래 달력 날짜를 유지한다. 기간 밖 제약은 먼저 수정해야 한다.
  범위 안 훈련 충돌은 기존 제약 판정으로 보여준다.
- 기간과 이동 가능한 세션은 같은 달력 일수만큼 이동하며 길이·시간대·ID·부모 관계를 유지한다.
- 영향 확인 뒤 한 번의 초안 변경으로 적용하고 기존 실행 취소로 전체 복구한다.
  계획 버전 저장은 별도 미리보기·명시 확인을 요구한다. 실제 기록·완료 이력은 변경하지 않는다.
- 완료 조회 실패·진행 중·버전 불일치에서는 이동을 검토하거나 적용하지 않는다.
