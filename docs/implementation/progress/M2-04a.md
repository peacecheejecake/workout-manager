# M2-04a · private text 자료와 버전 고정 reader

상태: **완료 (M2-04/FUT-06은 미완료)**. 직접 입력한 private text만 PostgreSQL에
저장하고, tenant 소유권·불변 버전·고정 문단 locator·목록/reader·명시 삭제를 web과
mobile-web에 연결했다. 파일/PDF upload, 객체 저장, URL 수집, parser, 검색/RAG,
인용, 검토 자료와 코치 사용은 구현하지 않았다. `includeForCoach=false`,
`reviewedState=unreviewed`, `contentStatus=parsed`, `indexStatus=not_indexed`를 계약과
저장소에서 명시한다.

Migration 027은 `resource`와 `resource_version`을 추가한다. FORCE RLS와 최소 runtime
권한, 저장 불가 제어문자를 제외한 64 KiB UTF-8 원문/1,000개 문단 제한, 불변 version chain, head CAS,
access revision, 멱등 receipt, 원자적 outbox를 적용한다. 삭제는 head tombstone을 남기고
현재·과거 reader와 기존 멱등 replay를 즉시 tombstone으로 바꾸며, 삭제된 원문은 계정
export와 command receipt에서 제외된다. tenant별 active 100개/1,000 version/4 MiB와
누적 2,000 version/16 MiB 상한을 transaction 안에서 검사한다. 계정 말소는
resource와 모든 version을 물리 삭제한다. export schema v12는 살아 있는 resource와
version만 포함하며 v1~v11 읽기 호환성을 유지한다.

API는 principal에서 소유자를 정하고 strict path/query/body, 헤더 멱등키, route별
create/append 192 KiB·delete 16 KiB 상한, 404/409/422 오류를 적용한다. web/mobile-web은 공유 모듈로 생성, 목록,
현재/정확한 과거 버전 reader, CAS 새 버전, 삭제 확인을 제공한다. reader는 AI 요약이나
인용이 아님을 표시하고, 검색 색인과 코치 사용이 꺼져 있음을 노출한다. 사용자·session
수명별 QueryClient와 query key를 사용하며 전체 서버 응답을 별도 Zustand 원장에 복사하지
않는다.
