# M1-01 · 표준 OIDC Identity·Consent

기준일: 2026-09-16. 상태: **완료** — 구현·로컬 검증·경쟁 조건 수정 후 독립 재리뷰 완료.

## 구현

- 사용자가 선택한 표준 OIDC: discovery, Authorization Code + PKCE S256,
  state/nonce와 서명·issuer·audience·expiry 검증. `openid-client`를 서버에서 사용한다.
- 계정 식별자는 issuer+subject이며 이메일로 계정을 자동 연결하지 않는다.
- 10분·일회성·브라우저 바인딩 로그인 attempt와 8시간 opaque 세션.
  DB에는 세션 token hash만 저장하고 로그인 완료 시 이전 세션을 원자적으로 교체한다.
- production은 HTTPS와 `__Host-` HttpOnly/Secure/SameSite=Lax cookie 사용.
  명시적인 개발 설정에서만 loopback HTTP를 허용한다. provider token은 보관·브라우저 노출하지 않는다.
- migration 002의 identity_private와 최소 SECURITY DEFINER 함수 경계.
  runtime은 private table을 직접 읽지 못하며 tenant consent는 기존 RLS/transaction/outbox를 사용한다.
- `/account`에서 로그인·동의 조회/허용/철회·로그아웃. Next는 Fastify에 same-origin proxy만 제공한다.
- Cookie 보호 요청은 예상 session ID를 검증하고, 쓰기는 Origin+CSRF를 추가 검증한다.
  다른 탭의 계정 전환은 이전 화면/cache 제거 후 세션을 다시 조회한다.
- 서버 응답은 세션별 QueryClient에만 저장한다. 토큰·건강 자료를 localStorage/sessionStorage에 넣지 않는다.
- 동의 변경은 expectedRevision+idempotency key를 사용한다. 재시도 receipt를 현재 상태로 표시하지 않고
  실제 최신 GET을 재조회하며 실패 중에는 과거 값을 현재 동의로 표시하지 않는다.

## 검증

- 전체 생성물/Prettier/ESLint/typecheck, Vitest 248개 통과.
- 실제 로컬 OIDC discovery/JWKS/token 서버에 PKCE·RS256을 적용한 프로토콜 시험.
  nonce·issuer·audience·expiry·서명 오류, 일회성 attempt, session 만료/회전/로그아웃 시험.
- 실제 PostgreSQL 22개: 병렬 attempt 소비, identity 매핑·session rotation rollback,
  직접 테이블 접근 및 PUBLIC EXECUTE 차단, 기존 consent/RLS/outbox 회귀.
- Production Next + Fastify + 전용 PostgreSQL + 로컬 OIDC provider Playwright 2개 통과:
  Alice 로그인·동의 저장/reload·로그아웃·Bob 격리, 세션 조회 지연 중 다른 탭 계정 전환.
- 컴포넌트 회귀: 과거 멱등 영수증 뒤 더 최신 철회, 세션 갱신 지연, 최신 조회 실패,
  401 만료 시 개인 화면 제거. 실제 provider 계정으로 시험한 것은 아니다.
- Aside 실제 브라우저에서 로컬 Alice OIDC 로그인→허용→철회→로그아웃 UI 확인.
  이후 경쟁 조건 수정은 Playwright/컴포넌트 회귀로 검증했다.
- Herdr split pane `workout-contract-review` (`wD:p6`)의 계정 전환·과거 receipt 표시 지적을 수정했다.
  재리뷰 findings 없음. 최종 기준 HEAD/staged tree는 커밋에 기록한다. GitHub CI job은 추가했지만 원격 미실행.

## 실행

```bash
pnpm build
pnpm test:identity  # 3100/4300/4400이 비어 있어야 함
```

`PG_BIN` 또는 감지된 PostgreSQL 바이너리로 독립 UNIX socket 임시 DB를 생성·종료·삭제한다.
상속받은 DATABASE_URL/TEST_DATABASE_URL을 쓰지 않는다. fixture 계정과 client secret은 로컬 시험 전용이다.
계속 실행하며 브라우저로 보려면 `pnpm exec tsx scripts/identity-e2e.mts`와
별도 터미널의 `pnpm --filter @workout/web start`를 실행한다.

실제 공급자 설정과 DB 준비는 [OIDC 운영 설정](../oidc-setup.md)을 참고한다.

## 한계

AI 동의는 저장·철회와 서버 revision 기반이다. 외부 AI 전송/코칭 기능은 아직 없으며
M1-05에서 전송 시점의 최신 동의 검사를 연결해야 한다. 파일/media API도 아직 없어 해당 ACL 수용은 후속 task다.
로그아웃은 이 앱의 세션을 폐기하며 공급자의 SSO 세션까지 종료하지 않는다.
실제 공급자 등록·배포 TLS/reverse proxy·native 로그인·HealthKit·운영 rate limiting은 검증하지 않았다.
홈 ActivityList의 개발 계정/메모는 fixture이며 인증된 실제 활동 DB와 연결되지 않았다.
