# M1-05j3a · 구조화 fixture·후보 서버 검증 API

상태: **completed**. M1-05j2의 불변 원장을 비프로덕션 구조화 fixture와 연결했다.
Fixture는 정확한 시간이 있는 첫 세션의 시간을 결정적으로 300초 변경하는 의도만
출력한다. 시간이 미확인인 계획에서는 후보를 꾸며내지 않고 추가 질문 상태로 끝낸다.
실행 출력은 계속 미검증 입력이며, 서버는 저장된 구조화 출력만 엄격히 파싱하고
현재 근거·의존성·동의·정책·계획·완료 보고를 재검사해 변경 한 건만 투영·검증한다.
클라이언트가 임의 계획이나 전략을 후보로 제출하는 경로는 제공하지 않는다.

비프로덕션 설정에서 본문 없는 후보 생성 POST와 소유자 조회·목록 GET을 연결했다.
생성은 실행 상태·후보 원장·digest·멱등 receipt를 한 transaction에 기록하며 현재
계획 head를 변경하지 않는다. 과거의 요약 전용 fixture 출력, 변조된 출력, 없는 세션,
stale 의존성, 철회된 동의는 후보로 만들지 않는다. 조회는 현재 유효한 후보 본문만
반환한다. 테스트용 브라우저 서버가 종료 신호를 직접 받도록 실행 명령을 조정해
임시 PostgreSQL 클러스터 정리를 확인했다.

부분 변경 요청과 본문 없는 stale 상태 표시는 M1-05j3b, 명시 계획 승인은 M1-05k다.

전체 격리 PostgreSQL 통합 테스트 215개, OIDC 실브라우저 E2E 3개,
unit/component 1,748개, 생성물·Prettier·ESLint·20개 패키지 및 루트 typecheck,
118개 노드 DAG 검사를 통과했다. Herdr split-pane 리뷰의 정확한 base/tree identity는
task 커밋 본문에 기록한다.
