# M0-03 · Host·상태·Next/Vite shell

기준일: 2026-09-16. 상태: **완료** — 구현·로컬 build/브라우저 검증·독립 peer review 완료.

Codex native agent가 공유 provider/API client/ActivityList를 구현하고 root가 두 shell·fixture host·E2E·CI를
통합했다. Vercel React Best Practices 및 Composition Patterns를 적용했다.

## 구현

- Next App Router와 Vite React shell에서 동일 `ActivityList`와 개발용 workspace를 렌더링.
- HostContext에 transport/capability를 주입. module/platform에는 Next import가 없다.
- Zustand store와 QueryClient를 provider마다 생성. 사용자/workspace/session 변경 시 렌더 전에 교체하고
  이전 요청·캐시·임시 메모를 제거한다. SSR 전역 singleton과 private localStorage는 없다.
- Query key에 사용자/workspace/session 포함. 서버 응답은 Query cache, 메모는 Zustand 소유.
- Transport 교체 시 sessionId도 변경한다. 개발 화면은 가상 활동/빈 목록/실패 후 재시도 adapter를 교체한다.
- Unknown과 0초 구분, 로딩/오류/재시도, 메모 초기화, 개발 계정 변경과 세션 종료/시작.
- 공유 컴포넌트는 의미 있는 HTML을 사용하며 shell은 최소 CSS만 제공한다. 정식 token/UI kit는 M0-04 범위.
- Next 생성물 next-env.d.ts는 생성 파일로 제외한다. Next 의존성/빌드는 고정 버전 16.3.5를 사용한다.

## 실제 검증

- Shared unit/component 13개 통과: SSR hydration/StrictMode, store/cache 격리, 취소/실패·재시도·transport 교체.
- 첫 설치 시 계약 JS 산출물이 없던 실패를 확인했다. test/coverage/watch 및 두 dev 명령은
  공개 계약 패키지를 먼저 빌드하도록 연결했다. Watch 중 계약을 수정하면 계약 build를 다시 실행한다.
- 전체 format/lint/typecheck/Vitest 205개 통과(병렬 API 18개 포함).
- Next production 및 Vite production build 통과. Vite에서 RSC `use client` 지시어가 무시되는 경고는
  CSR bundle 동작에 영향을 주지 않았다.
- Production HTTP 서버 Playwright 4개 통과: Next desktop/Vite mobile, 320/768/1280 resize 메모 유지,
  가로 overflow 검사, 계정·종료 초기화, 빈 상태, 재시도 시 메모 보존, pageerror 없음.
- Aside 실 브라우저: Next에서 한글 메모 입력→계정 A/B 전환 시 메모 제거·목록 교체 확인.
  Vite에서 오류→한글 메모 입력→재시도 성공 및 메모 보존 확인.
- Herdr `workout-contract-review`, split pane `wD:p6`: findings 없음. Reviewer가 13개와
  StrictMode 지연 query cleanup 복구 임시 시험 1개를 직접 실행했다.
- 기준 HEAD와 staged tree는 task 커밋 메시지에 기록한다. 원격 CI는 미실행이다.

## 실행·한계

```bash
pnpm dev:web         # http://127.0.0.1:3100
pnpm dev:mobile-web  # http://127.0.0.1:4200
pnpm build
pnpm test:shells     # production build 필요, 포트는 비어 있어야 함
```

개발 화면은 가상 데이터이며 실제 로그인·Activity DB·공식 연동이 아니다. Native/HealthKit도 구현하지 않았다.
Aside 한글 입력은 OS IME 조합 시험을 대체하지 않는다. 디자인 시스템·반응형 renderer·키보드/터치 전체
수용 범위는 M0-04 이후다. Host의 production transport와 API 연결은 실제 인증 도입 후 구성한다.
