# M1-05g · 필수 제약을 포함한 근거 버전

상태: **completed**. 선행 M1-05d/e/f 완료.

신규 running-core-v2 근거는 사용자 필수 제약 전체와 core-ledgers-v2의 제약 head를 같은
시점에 포함한다. 과거 v1 본문은 그대로 읽으며 제외되었던 제약을 소급 합성하지 않는다.
정정은 과거 근거를 유지하며 revision 비교로 변경을 감지하고, 삭제는 포함된 근거를 회수한다.
기간·상담 범위 선택으로 필수 제약을 제외할 수 없다. 정책·AI 실행·전체 승인 gate는 별도다.

복원은 최신 외부 제약 원장에 따라 바뀐 행만 반영해 유지 중인 근거를 불필요하게 회수하지
않는다. 삭제된 제약이 포함된 근거는 runtime 접근 전에 폐기한다.

Herdr 분리 pane 독립 리뷰에서 제약 삭제 후 열린 근거 본문이 남는 문제를 발견했다. 제약
변경 성공 시 근거 조회 cache를 초기화하도록 수정했고, query key 재검토에서 나온 불일치도
고쳤다. 최종 재검토에서 추가 actionable finding이 없었다. 삭제 직후 수동 재조회 없이 본문
폐기를 확인하는 E2E가 통과했다.

Aside 실제 브라우저에서 합성 OIDC 계정으로 제약·상담·v2 근거를 저장하고, 제약 삭제 직후
선택한 근거가 수동 새로고침 없이 “본문 폐기”로 바뀌는 것을 확인했다.
