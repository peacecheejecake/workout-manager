# M3-01f · 제품 iOS shell 키보드·Back·foreground 수명주기

상태: **completed (로컬 수용 범위)**. 기준 `phase/m3-01` `5f47c0f`. 제품 Capacitor shell의 제한된 계정·초안 흐름에 native 키보드, Back, foreground 처리를 연결한다. 실제 제품 전체 화면 통합과 서명된 실기기 검증은 후속이다.

## 수용 범위

- 가로 화면에서 한국어 입력 포커스와 커서가 열린 native 키보드 위에 보이고 회전·키보드 프레임 변화 후에도 다시 드러난다. 닫힐 때 기존 inset을 복원한다.
- 미저장 초안에서 Back 버튼과 왼쪽 가장자리 제스처는 계속 편집/뒤로 이동 확인을 거친다. 계속 편집은 입력을 보존한다.
- foreground 복귀는 서버 세션을 재확인한다. 일시적 오류에는 개인 초안을 보존하고 401·계정 변경 시에는 개인 범위를 지운다. 변경 중인 화면을 외부 인증 완료로 추정하지 않는다.

## 검증

- iOS `LocalBridgeViewController`는 keyboard frame/rotation을 WebView 좌표로 바꾸어 스크롤 inset을 조정하고 포커스된 입력을 드러낸다. 키보드가 닫히면 원래 inset을 복원한다. 자동 WKWebView back swipe 대신 왼쪽 가장자리 gesture에서 고정 `workout:native-back` 이벤트를 로컬 origin에만 보낸다. scene active 때 `workout:native-foreground`를 보낸다.
- mobile-web의 실제 native entry에는 계정에서 여는 로컬 임시 메모가 있다. 서버 저장으로 표시하지 않는다. Back 버튼·native edge 이벤트·browser history가 미저장 확인을 거치며 계속 편집은 메모와 포커스를 보존한다. IME 조합 중 Back은 입력을 끊지 않는다. 로그아웃/401/계정 교체는 개인 저장소·메모·이전 계정 history scope를 지운다. foreground 일시 오류는 메모를 지우지 않고 계정 상태 불확실성을 표시한다.
- `pnpm install --frozen-lockfile`, `pnpm check:generated`, `pnpm lint`, `pnpm typecheck`, `pnpm build` 통과. 타입 34/34, 빌드 15/15. 첫 전체 타입 검사에서는 신규 시험 파일의 모듈 참조·조회 옵션 오류가 발견되어 수정한 뒤 다시 통과했다. 포맷·차이 검사도 통과했다.
- 전체 단위 시험은 4,174 통과/7 제외, 실제 임시 PostgreSQL을 사용하는 통합 시험은 811 통과. 루트 최종 집중 시험 7/7 통과(경고 없음). Agent의 iOS Swift 구문 검사와 unsigned Simulator 빌드도 통과했다. 전체 identity Playwright 두 회는 각각 302 통과/13 제외(14.4분, 14.3분)였다.
- 첫 도구 경로인 Aside 갱신은 `fetch failed`였다. Chrome에서 임시 로컬 test harness의 합성 Capacitor bridge로 제품 native entry를 열어 한국어 메모 입력, 버튼 Back의 미저장 확인, 계속 편집의 값·포커스 유지, 뒤로 이동 뒤 계정 복귀, Forward의 빈 메모, 브라우저 Back의 미저장 확인을 관찰했다. 임시 harness와 서버는 종료·삭제했다. 이는 WebView edge gesture나 실제 서버 세션의 증거가 아니다.
- `devicectl`에서 iPhone 15 Pro Max가 `available (paired)`이고 `org.workoutmanager.app`이 미설치임을 확인했다. Keychain의 Apple Development 서명 1개도 확인했다. 최종 웹 dist를 `cap copy ios`로 복사하고 두 `index.html` SHA-256 일치를 확인했으며, 루트의 unsigned iOS Simulator 빌드가 통과했다. 서명된 iPhone 빌드는 Xcode의 `No Accounts` 및 `No profiles for 'org.workoutmanager.app'`로 실패했다. 기기 설치·실제 가로 한국어 입력, Back 버튼과 edge gesture, foreground 재확인 성공은 **not_executed**다. 기본 Info.plist의 운영 HTTPS API/IdP origin은 비어 있으므로 현 빌드의 인증 성공을 추정하지 않는다.
