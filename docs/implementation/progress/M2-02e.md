## 구현

Thin Fastify plugin으로 RaceEvent/RaceResult/TrainingBest의 create/update/get/bounded list를 연결했다. tenant는 기존 auth principal에서만 얻으며 글로벌 세션·cookie CSRF를 상속한다. POST/PATCH body 16KiB, query cursor 2048자와 limit 1–100, idempotency-key 헤더만 허용하고 서버 verifiedAt/owner를 거절한다. 읽기와 응답은 runtime schema로 검증하며 no-store, revision-only ETag 없음이다. CAS/stale cursor/Plan 영향/참조 오류는 stable sanitized 오류로 매핑한다. Root가 configured/product registry와 identity/local OIDC/backup/Lightsail bootstrap의 grantRaces를 통합했다.
