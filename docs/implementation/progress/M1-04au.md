# M1-04au · 활동 상세 URL 탭·관측 상태 보존

상태: 구현·검증 완료. S09 / V2-F13.

- 목록 `view`와 별개인 `detailTab` URL로 개요·구간·영향·출처를 탐색한다. 필터·정렬·페이지·선택을
  보존하고 뒤로 가기·새로고침으로 탭을 복원한다. 잘못된 상세 탭은 목록 조회를 무효화하지 않는다.
- 출처·수정 여부·요약 관측 시각·거리·시간·페이스·심박은 공통 상단에 둔다. 관측 시각은
  read model 조회 시각이며 실제 운동 종료 시각으로 해석하지 않는다.
- 관측 상태 소유자를 유지하면서 비활성 차트·표 DOM을 해제한다. 같은 활동/원본 revision에서
  선택·차트/레코드/랩 페이지·UTC 범위 입력·검증 오류가 탭 전환에도 남는다.
  활동/원본 identity 변경 또는 새로고침에서는 이 일시 상태를 초기화한다.
- 경로·미디어 탭은 제공 불가 사유와 함께 비활성화한다. 현재 계약에 GPS가 없다는 사실을
  실제 GPS 기록이 없다는 결론으로 확대하지 않는다. 직접 URL은 사유와 개요 복구를 제공한다.
- 방향키·Home/End로 활성 탭만 이동한다. 수정 키·IME 조합은 가로채지 않는다.
  API/DB 계약과 기존 상세 버전 일치·실패/재조회·계정 격리 경계는 유지한다.
