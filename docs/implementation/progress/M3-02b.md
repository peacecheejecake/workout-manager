# M3-02b · HealthKit 운동 native 증분 수집·영속 outbox

상태: **로컬 수용 완료**. `phase/m3-02`의 로컬 구현 하위 작업이며 독립 phase 검토 전이다.

## 범위

- 제품 iOS 앱에서 `HKWorkout`의 증분 추가·삭제를 제한된 페이지로 수집한다.
- 조회 anchor, 표본 UUID 대응표, 재전송할 배치 ID·본문을 함께 영속 저장한다. 서버가 정확한 ACK를 돌려준 배치만 제거한다.
- 네이티브 Keychain bearer와 고정 HTTPS 수신 경로만 사용한다. 계정 변경·로그아웃·동의 철회·인증 실패에서 이전 소유자의 건강 자료가 전송되지 않도록 한다.
- observer/background delivery는 재시도 신호로만 취급한다. OS 실행 보장이나 빈 조회로 읽기 권한 상태를 추정하지 않는다.
- 403(동의 오류 이외)·409·영구 입력 오류의 배치를 기기에 보류하고 원본 본문을 보존한다. 보류된 첫 배치 뒤의 전송 순서도 유지한다. 최대 256개 배치로 기기 저장량을 제한한다.

## 로컬 검증 기록

- `HealthKitWorkoutStateHarness.swift`: anchor·outbox 원자 저장, 재시작 후 동일 본문, 정확한 ACK, 배치 보류의 지속성, 계정 전환·reset 삭제, 훼손 본문 거부, 256개 상한을 독립 실행으로 확인했다.
- `HealthKitWorkoutUploaderHarness.swift`: 본문 상한·배치 식별, ACK 식별과 건수, 401·403·409·400·429 분류를 독립 실행으로 확인했다.
- iOS SDK Swift 타입 검사와 Swift 구문 검사, Xcode plist 검사가 통과했다. `pnpm --filter @workout/mobile-web build` 및 `pnpm --filter @workout/mobile exec cap copy ios`로 별도 worktree에 필요한 무시된 자산을 만든 뒤, `CODE_SIGNING_ALLOWED=NO`인 iOS Simulator 전체 앱 빌드가 통과했다. 첫 빌드는 그 자산이 없어 Swift 컴파일 전에 실패했다.
- 생성물 검사, 전체 Prettier 검사, ESLint, TypeScript typecheck 34/34가 통과했다. 전체 단위 검사는 **4,191 통과·7 건너뜀**, 실제 PostgreSQL 통합 검사는 **818 통과**와 업그레이드 검사 **1 통과**였다. 일반 Playwright E2E 직렬 재실행은 **4 통과**, 전체 앱 빌드는 **15/15 통과**였다. 브라우저 identity 전체 재실행 2회는 각각 **302 통과·13 건너뜀**이었다. 건너뛴 외부 데이터 조건을 통과로 바꾸지 않는다.
- 첫 `test:identity` 실행은 별도 worktree에 무시된 `.geo-build` 지도·장소 자산 경로가 빠져 코스 검사 실패가 발생해 중단했다. 기존 검증 자산의 절대 경로를 `IDENTITY_E2E_BASEMAP_DIST_DIR`와 `IDENTITY_E2E_GEO_DATA_DIR`에 지정해 전체 검사를 다시 시작했다. 이 중단 실행은 통과 증거가 아니다.
- 그 재실행 도중 `test:e2e`를 같은 작업 트리에서 병렬 실행해 Playwright 결과 파일이 충돌했다. `test:e2e` 3/4 통과·1 실패 및 identity 1건 실패 뒤 두 실행을 중단했다. 브라우저 검사를 직렬화한 `test:e2e` 재실행은 **4/4 통과**했고, identity 첫 전체 재실행은 **302 통과·13 건너뜀**이었다. 앞선 병렬 실행을 통과로 세지 않는다.
- 루트의 첫 Simulator 빌드 재실행은 sandbox가 CoreSimulator/SwiftPM 캐시에 접근하지 못해 실패했다. 로컬 Xcode 서비스 접근 권한과 임시 module cache를 지정한 재실행은 `BUILD SUCCEEDED`였다.

## 판정 경계

로컬 Swift 상태·전송 검증과 서명 없는 Simulator 빌드를 이 노드의 수용 범위로 둔다. `requestReadAuthorizationFromProductAction`을 호출하는 제품 화면이 아직 연결되지 않았다. HealthKit 권한 요청, 실제 표본·삭제·background wake, 서명된 iPhone에서의 서버 도달, 화면 표시·정본 Activity 연결은 현재 `not_executed`이며 M3-02 부모·후속 통합에서 별도 확인한다. 배치 보류의 사용자 복구 동작도 후속 제품 연결이 필요하다.
