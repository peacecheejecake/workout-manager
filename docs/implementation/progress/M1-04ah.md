# M1-04ah · 기간 타임라인·URL 보기 전환

상태: 완료. S04 §5.2의 기간 타임라인을 기존 탐색과 연결했다.

## 범위와 의미

- `buildPeriodNavigation`의 동일 날짜·자식 정렬·비율을 사용한다. 막대의 위치와 길이는
  날짜 범위이며 훈련량·수행률·우선순위 크기가 아니다. 미배정 간격·부분 기간을 보존한다.
- `periodView=orbit|timeline`은 URL 상태다. Orbit/타임라인/동일 목록에서 기간 선택,
  breadcrumb와 미리보기를 공유한다. 보기 변경은 세션 선택·초안·필터를 초기화하지 않는다.
- 짧은 막대에도 키보드·목록 대안을 제공한다. hover/focus는 미리보기이며 클릭/Enter로
  선택한다. 날짜 이동·resize·계획 저장·실제 활동 생성은 이 기능의 동작이 아니다.
- 저장된 기간 요약은 기존 저장 head 기준을 유지한다. 기간 타임라인은 유효한 초안도
  탐색할 수 있지만 이를 저장 결과나 실제 관측으로 표시하지 않는다.
- S04의 보기 전환과 V2-F06 계층/partial, V2-F08·V2-A12 동일 선택/목록 대안을 연결한다.
  대회·시나리오 branch·기간 이동 확인은 별도 미완료 범위다.
- 기존 기간 요약 패널에서 미정의 radius 이름을 실제 `radius-control` 토큰으로 수정했다.
