# M1-05i2b2a · 결정론 실행 runner·직전 검사

상태: **completed**. 선행 M1-05i2b1 완료.

tenant를 명시해 `coaching.run_queued` topic만 lease로 가져오는 worker port를 추가했다.
작업 직전과 adapter 결과 저장 직전에 근거 v2, 대화 revision, 현재 core 원장 의존성,
AI 동의, 서버 정책 버전, fixture 출처를 다시 확인한다. 모델/adapter 호출은 DB transaction
밖에서 실행한다. 여섯 번째 재획득은 adapter를 호출하지 않고 제한된 내부 오류 상태로
종결한다. lease를 잃은 worker의 결과는 저장하지 않는다.

결정론 `synthetic-v1` adapter의 결과는 내부 미검증 출력으로 저장한다. 출력·실행 상태·
outbox 완료는 한 transaction으로 묶는다. JSONB 저장 크기를 DB 표현 기준으로 검사해
제한을 넘는 결과도 `invalid_output`으로 종결한다. 질문과 오류는 terminal 상태로 기록하고,
취소·동의 철회·근거/대화/정책 변경은 실행 전후에 출력을 막는다. 이 결과는
`validated_final`, Decision, Proposal 또는 승인된 PlanVersion이 아니다.

전용 worker 역할에는 필요한 원장 읽기, 상태/lease 열 쓰기, 출력 삽입만 부여하며
출력 조회 권한은 주지 않는다. 일반 `createConfiguredApi`에는 실행 경로를 연결하지 않았고,
배포용 credential·tenant dispatch와 API 결과 복구·E2E는 M1-05i2b2b 범위다.

검증: 임시 PostgreSQL integration 24파일·203개(tenant 격리, 정책·대화·동의 변경,
중복 lease, 6회 제한, adapter 실패/질문, JSONB 크기 경계, ack rollback 포함), 변경 패키지 typecheck,
