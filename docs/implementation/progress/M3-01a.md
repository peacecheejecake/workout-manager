# M3-01a · Native bridge 계약·웹 어댑터 경계

상태: **completed**. 기준 `main` `f04bda6`. 선행 `M1c-04`와 `M0-06c`는 완료됐다. 제품 native host 전체인 `M3-01`은 이 노드 뒤에도 별도 작업·검증이 필요하다.

첫 범위는 번들 WebView와 native plugin 사이의 versioned handshake, 명시적 capability, 허용된 명령, request/reply ID, timeout/cancel 및 `unknown` 경계 검증이다. 초기 명령은 `app.openSettings` 하나만 허용한다. HealthKit·인증 transport는 이 단계에서 unavailable이며, 원시 건강 자료·임의 URL fetch/eval·토큰은 bridge에 싣지 않는다. 같은 버전이 아닌 오래된 앱은 명시적인 unsupported 결과를 받는다.

수용 조건: 정상 handshake·명령·오류·취소·시간초과, 잘못된 버전·메서드·ID·응답 payload를 행동 시험으로 확인한다. `M0-06c`의 probe 실행은 제품 앱의 서명·설치·Back/IME·인증·HealthKit 실기기 증거가 아니다. 이 노드에서 그런 항목의 `not_executed`를 passed로 바꾸지 않는다.
