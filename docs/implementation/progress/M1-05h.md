# M1-05h · 훈련 승인 read basis 계약

상태: **completed**. 선행 M1-04·M1-05g 완료.

`running-core-v2`의 사용 가능한 근거만 training-only read basis로 만든다. 근거 ID, 소유자,
고정 계획 버전, 상담 revision, core-ledgers-v2의 부재 head를 포함한 전체 원장 의존성,
서버가 제공해야 할 정책 identity/version, 자료 검색을 사용하지 않았다는 `retrieval: none`을
명시한다. 근거 본문이 폐기됐거나 과거 v1이거나 현재 계획 head와 고정 계획이 다르거나 AI
전송 동의가 없으면 basis 생성을 거절한다.

순수 비교는 근거 회수, 대화·정책·원장 revision 변화를 stale로 표시하고 소유자·증거 ID·
버전·지원하지 않는 자료 의존성·알 수 없는 필드는 fail-closed로 거절한다. 캡처 시각은
revision이 아니며 근거 생성 시각과 같다고 가정하지 않는다. 이 계약은 사용자 권한을
부여하거나 후보를 생성하거나 계획을 저장하지 않는다. 서버가 실제 정책을 선택하고 승인
transaction 안에서 최신 근거와 전체 의존성을 다시 검사하는 작업은 M1-05i~k에 남는다.

검증: `pnpm check --maxWorkers=2`의 153개 파일·1717개 unit/component 시험과 18개
typecheck, 계약 단위 시험 14개, contracts build, 변경 파일 ESLint·Prettier, DAG·문서 링크·
diff 검사 통과. 로컬 fixture가 포트를 여는 시험은 로컬 서버 권한으로 실행했다. 실제 모델·
DB 승인·브라우저 경로는 이 task의 시험 대상이 아니다.

Herdr 분할 pane 리뷰의 base/tree identity와 최종 결과는 이 task 커밋 본문에 기록한다.
