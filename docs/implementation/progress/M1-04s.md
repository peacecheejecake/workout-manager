# M1-04s · 계획 표 고정 열·범위 선택·가상 스크롤

상태: 구현·검증 완료. V2-F09 / S05의 표 상호작용을 확장한다.

## 범위

- 고정 열은 검증된 URL 상태로 공유하고 좁은 컨테이너에서는 요청을 유지하며 고정을 해제한다.
- 범위 선택은 상세 세션 선택과 분리된 workspace Zustand 상태다. 현재 정렬 순서로 범위를 선택하며
  키보드·터치 시작/끝 조작, 선택 해제를 제공한다. 선택만으로 계획이나 실제 기록을 쓰지 않는다.
- 많은 행은 동적 높이 가상 스크롤로 표시하고 전체 행 표시 대안을 제공한다.
- 반응형 보기 전환에서 범위·스크롤 위치·초안을 보존한다.
- DnD/시간 resize·Orbit·대시보드 편집·S09 연결 workbench는 별도 잔여 범위다.

## 구현 근거

- `@tanstack/virtual-core` 3.17.11을 lockfile로 고정했다. 설치된 MIT LICENSE를 확인했다.
  배포 notice 전체 동봉 검증은 기존 M0-06b 잔여다.
- 동적 측정과 scroll margin은 [TanStack Virtual API](https://tanstack.com/virtual/latest/docs/api/virtualizer)를 따른다.
- React adapter의 mutable API는 설치된 React lint에서 호환성 경고를 발생시켰다.
  core의 공식 lifecycle을 연결하고 `useSyncExternalStore`로 불변 snapshot을 제공하도록 구현했다.
  ESLint·AGENTS·스킬 규칙과 compiler 설정은 변경하지 않는다.
