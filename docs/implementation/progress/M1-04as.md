# M1-04as · 활동 페이스·심박 요약

상태: 구현·검증 완료. 제품 명세 §7.2 S09의 거리·시간·페이스·심박 요약.

- FIT session의 평균·최대 심박을 출처 그대로 보존한다. 레코드·랩의 평균이나 보간으로 채우지 않는다.
  [Garmin 공식 FIT profile](https://github.com/garmin/fit-python-sdk/blob/main/garmin_fit_sdk/profile.py)의
  session 필드 16/17, bpm 단위를 확인했다. 기술적 값 범위를 생리적 유효성으로 해석하지 않는다.
- 새 opt-in 상세 export는 envelope v3 / details v2 / source revision 3,
  `fit-details-v2-…` 키다. 기존 sourceId·contentHash를 유지한다. summary-only export v1은
  그대로이며 기존 상세 export v2 / details v1도 읽고 필드 부재를 보존한다.
- details v2의 `sessionSummary`는 평균·최대의 null과 0을 구분한다. 기존 JSONB 저장·export v4가
  출처 이력을 보존하며 새 테이블이나 계정 export 버전은 필요하지 않다.
- `activity-duration-distance-pace-v1`은 한 활동 값 집합의 `(durationSeconds / distanceMeters) × 1000`
  초/km다. running/walking/cycling에 적용하고 timer/elapsed/moving 정의를 보존한다.
  미확인 종목·시간 정의, null·0, 표현 범위 초과는 명시적으로 제공 불가로 표시한다.
- 화면은 원본/정정 반영 페이스를 별도로 계산한다. 초 단위 반올림을 표시하고 1초 미만은 별도 표기한다.
  심박은 활동 ID·canonical revision·source identity가 맞는 상세에 한정하며 loading/error/legacy/미보고를 구분한다.
  페이스의 재계산은 출처 심박을 변경하지 않는다.
