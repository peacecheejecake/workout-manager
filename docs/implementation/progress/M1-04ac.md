# M1-04ac · 세션 단계 순서 편집

상태: 완료. S06 / V2-F11의 기존 단계 편집을 순서 변경으로 확장했다.

## 범위

- 단계별 위/아래 버튼으로 순서를 변경한다. 키보드·터치로 같은 동작에 접근하고
  첫/마지막 경계, 현재 순서 안내와 이동 후 포커스를 제공한다.
- 기존 배열 순서와 stable 단계 ID를 유지한다. 종류·시간·거리·반복 및 `null`/`0`을
  보존하고 세션 총량이나 실제 수행 기록을 자동 계산·변경하지 않는다.
- 공유 Zustand 초안에만 반영하고 기존 전후 미리보기·명시 저장·취소를 사용한다.
  저장된 강도 잠금은 순서 변경도 차단하며 별도 버전으로 잠금을 먼저 해제해야 한다.
- 계약·migration 변경은 필요하지 않다. 단위 전환 확인, 범위·pace/HR 목표,
  참석 잠금과 시간대 이동은 이 순서 편집 작업에 포함하지 않는다.

- 신규 컴포넌트 4 tests와 기존 계획·복제·강도 라벨 33 tests 통과. 키보드 이동,
  ID/값/원본 baseline 보존·undo·경계 포커스·잠금 선행 해제·빈/단일 단계를 검증했다.
  최초 format 검사에서 새 시험 파일의 줄바꿈을 교정하고 재검사를 통과했다.
- `pnpm check --maxWorkers=2`: generated/format/lint/typecheck 및 75 files / 891 tests 통과.
  기존 대용량 차트의 기본 병렬 timeout 문제는 M1-04aa/ab 기록과 같으며 설정은 변경하지 않았다.
