# M1-04z · 활동 다중 선택·일괄 로컬 삭제

상태: 구현·검증 완료. S07 / V2-F12의 명시적 대량 삭제 요구를 기존 로컬 삭제 API에 연결했다.

## 범위

- 상세 선택 URL과 별도로 사용자·세션 수명의 Zustand에서 최대 100개 활동을 선택한다.
  현재 페이지 선택은 검색 결과 전체 선택이 아니다. 페이지/필터 변경 뒤에도 선택 개수를
  표시하고 기존 선택 당시 revision을 자동 갱신하지 않는다.
- 삭제 확인 시 ID·revision·표시 제목·출처를 고정한다. 명시 확인 후 기존 DELETE를 순차
  실행하고 항목별 결과를 표시한다. 여러 삭제 전체가 하나의 transaction이라고 주장하지 않는다.
- 204 확인만 성공 처리한다. 409는 최신 기록 재검토·재선택, 404는 접근 불가로 표시한다.
  응답 불명은 같은 ID/revision으로만 재확인한다. 취소 전 미전송과 전송 후 불확실을 구분한다.
- 인증 실패·계정 전환·unmount 시 이후 요청을 중단한다. 성공 항목을 선택에서 제거하고
  상세/목록을 무효화한다. 재조회 실패와 확인된 삭제 성공을 구분한다.
- provider 원본 삭제·전체 계정 삭제와 구분하며 기존 suppression을 유지한다.
  로컬 태그·일괄 계획 연결·export는 별도 미완료 요구다.

## 검증

- `pnpm check`: 69 files / 836 tests 통과. production build 7 tasks 통과.
- 순수 선택/실행 10 tests, 삭제 UI 8 tests, browser 관련 39 tests 통과.
  100개 초과 전체 거절, 선택 잠금·revision 보존, 첫 성공 즉시 상세 닫기,
  지연된 다음 요청·계정 전환 후 응답·abort·인증 실패 중단·재조회 실패를 검증했다.
- 신규 실제 API/격리 DB OIDC E2E 1 test 통과. 3개 대상 중 204 성공·미리보기 이후 수정으로
  409·서버에서 삭제한 뒤 응답만 유실되는 경우를 함께 검증했다. 미확인 재시도는 같은
  revision을 사용하며 집계를 중복 감소시키지 않는다. 충돌 대상은 최신 revision을 명시
  재선택 후 삭제했다. suppression, 14개 viewport 포커스/선택/320px reflow도 확인했다.
- 전체 실제 API/격리 DB OIDC E2E 56 tests 통과. 첫 전체 실행에서 선택 열 추가로 기존
  거리/시간 검증의 위치 기반 selector가 실패했다. 0/미확인 값을 이름으로 직접 확인하도록
  수정한 뒤 전체 재실행을 통과했다. 서버/DB 정책은 기존 API를 사용한다.
- Aside 실제 브라우저에서 합성 활동 2개 업로드·명시 저장 → 현재 페이지 선택 → 미리보기
  선택 잠금 → 취소와 트리거 포커스 복귀 → 재확인 삭제 → 항목별 성공·목록 0개·결과 닫기
  후 제목 포커스를 확인했다. `batch-delete-preview.png`와 `batch-delete-result.png`를 직접
  열어 확인했다. 개인 데이터 없이 격리 DB에서 실행했고 테스트 탭·서버를 정리했다.
- 커밋 전 Herdr 독립 split-pane 리뷰의 base/tree, 결과와 검증 증거는 커밋 본문에 기록한다.
- 첫 Herdr 리뷰에서 실제 transport가 인증 만료를 `SESSION_EXPIRED` 예외로 전달할 때
  다음 삭제 요청이 실행될 수 있는 P2를 발견했다. 해당 예외는 재인증 필요와 즉시 중단,
  `SESSION_UNAVAILABLE`은 현 요청 불확실과 이후 미실행으로 분리했다. 실제 session
  transport의 401·세션 변경·요청 전후 비활성화 회귀 4개를 추가했으며 최종 실행 결과는
  커밋 본문에 기록한다.

규칙 및 외부 출시 gate는 변경하지 않는다.
