## 범위

- 세션 intensityLabel 미지정/A/B/C를 독립적인 계획 라벨로 편집한다.
  scenario A/B/C 및 목표 RPE와 구분하며 생리적 의미·자동 변환을 부여하지 않는다.
- 선택 상세·전후 미리보기·계획 표에서 표시하고 명시 저장·reload·복제 시 보존한다.
- baseline intensity 잠금이 라벨 변경도 차단하며 해제와 변경을 동시에 저장할 수 없다.
- optional nullable 계약으로 과거 snapshot·receipt의 필드 누락을 보존한다.
  필드 누락/null은 잠금 비교와 표시에서만 같은 미지정으로 취급한다.
- 날짜 이동·길이 조절이 라벨을 보존하고 기존 0/null 및 actual 데이터는 변경하지 않는다.
- pace/HR target·거리/시간 범위·course·전체 semantic provenance는 남은 별도 범위다.
