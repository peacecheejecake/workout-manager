# M0-04 · UI·반응형 기반

기준일: 2026-09-16. 상태: **완료** — 구현·로컬 검증·독립 재리뷰 완료.

## 구현

- `@workout/ui-foundation`: Button, TextField/TextAreaField, StatusNotice, AdaptiveWorkspace.
- `.pre/design-tokens.css`와 `responsive-spec.json`에서 semantic tokens, responsive CSS/TS,
  container CSS, Storybook viewport를 생성. 원본 설계·규칙은 수정하지 않았다.
- Next/Vite 동일 활동 화면에 토큰·CSS Modules·명시적 stack/split 보기 적용.
  컨테이너 크기에 따라 동일 DOM을 재배치하여 Zustand draft와 focus를 보존한다.
- 입력 label/설명/error 연결, keyboard focus, 44px 기본/48px quick-log target,
  reduced motion, 색상 외 밑줄로 선택 상태 표시.
- Storybook Alpine/Aurora/Solid 및 loading/empty/partial/error/stale/unavailable/sync-pending 예제.

## 검증

- 생성물 `--check`, format/lint/typecheck 및 UI component 16개 통과.
- Next/Vite/Storybook production build 통과.
- Next desktop/Vite mobile Playwright 8개 통과: 생성 viewport 320–1920px,
  좁은 420px container, 메모·focus 유지, 한글 composition event, 키보드 선택,
  reduced motion, 200% 글자 확대, overflow 및 기존 계정/오류 회귀.
- Aside 실 브라우저: 한글 메모 입력·보기 변경 시 보존, 선택 버튼 밑줄 computed style 확인.
  Storybook Aurora 실제 스크린샷과 DOM에서 canvas `rgb(28,32,65)`, ink `rgb(245,245,255)` 확인.
- Aside REPL에는 `setViewportSize`가 없어 해당 API를 이용한 resize는 수행하지 못했다.
  viewport matrix는 자동 Playwright로 검증했다. OS IME·native device 검증으로 주장하지 않는다.
- Herdr split pane `workout-contract-review` (`wD:p6`)의 선택 상태·Aurora 배경 지적을 수정했다.
  재리뷰 findings 없음. 최종 기준 HEAD/staged tree는 커밋에 기록한다. 원격 CI는 미실행.

## 실행·한계

```bash
pnpm generate:responsive
pnpm check:generated
pnpm dev:storybook  # http://localhost:6006
pnpm build
pnpm test:shells
```

활동은 개발 fixture다. 이 작업은 공통 controls/반응형 기반이며 전체 제품 화면·복합 UI·native
수용 완료가 아니다. Storybook bundle 경고는 남아 있으며 제품 bundle과 별도다.
