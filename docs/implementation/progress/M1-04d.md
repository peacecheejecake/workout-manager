## 구현

- 기준일·3~90일 기간·IANA 시간대는 URL 상태다. 7/10/14/28일 preset, 뒤로가기,
  잘못된 입력 안내와 복구를 제공한다. 적용된 계획 시간대와 요청 시간대를 구분한다.
- 계획 버전·Block·기준일 및 가까운 계획 세션, 현재/직전 창의 실제 기록과 계획값을 분리한다.
- 시간은 timer/elapsed/moving/unknown 정의별로 표시하고 합치지 않는다. 미보고와 관측 0,
  알려진/미보고 건수, FIT/fixture 출처·정정 건수를 보존한다.
- 날짜별 거리 그래프·표는 같은 days를 사용한다. 알려진 0만 점을 표시하고 미보고는 그리지 않는다.
  그래프·표 모듈은 지연 로딩하며 가로 탐색 버튼으로 키보드 조작을 지원한다.
- 최신 체크인은 ID로 상세에 연결한다. 대시보드 투영 날짜와 저장된 현지 날짜가 다른 경우에도
  wellbeing 날짜 필터로 오해하여 연결하지 않는다.
- TanStack Query를 사용자·세션 수명으로 격리한다. 변경된 기간에 이전 기간 값을 표시하지 않으며,
  같은 기간 재조회 실패는 마지막 관측 시각과 오래된 기록 안내를 함께 유지한다.
- 수집 완전성·확정 이행률·생리 지표·AI 제안·자동 동기화 성공을 만들어 표시하지 않는다.
