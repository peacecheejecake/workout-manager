# M1-04ab · 선택 활동 요약 JSON 내보내기

상태: 완료. S07 / V2-F12 선택 활동 내보내기의 요약 파일 범위를 구현했다.

## 범위

- 기존 최대 100개 선택·사용자/세션 수명·일괄 작업 잠금을 공유한다.
- 항목별 GET에서 선택한 ID/revision을 확인하고 하나라도 충돌·삭제·조회 실패이면 파일을
  만들지 않는다. 선택을 자동 최신화하거나 성공한 항목만 조용히 내보내지 않는다.
- `selectedActivityExportSchema`는 기존 FIT 수입 명령과 구분되는 version 1 JSON 파일이다.
  source/original/effective/overlay/userReport, null/0, 시간대·측정 정의를 보존한다.
  항목별 확인 결과이며 단일 시점 DB snapshot을 보장하지 않는다.
- 명시적 미리보기·파일 생성·다운로드를 제공하고 취소·계정 변경·닫기 시 요청과 Blob URL을
  정리한다. 건강 기록을 localStorage에 저장하지 않는다. 최대 파일은 UTF-8 8 MiB다.
- 레코드·랩·GPS 상세와 재가져오기, native 파일 공유는 이 요약 파일 범위에 포함하지 않는다.
  계정 전체 내보내기 기능 및 기존 원본 수집·삭제 정책은 유지한다.

## 검증

- 계약 5 tests, 실행기 8 tests, 내보내기 UI 8 tests, 목록·상호 잠금 관련 42 tests 통과.
  null/0·legacy 보고 부재·중복/초과/잘못된 형식, 전체 조회 성공 조건, 실제 transport의
  인증/세션 중단, 닫기·계정 교체·늦은 응답과 Blob 폐기를 검증했다.
- production build 7 tasks 통과. 실제 API/격리 DB 신규 다운로드 E2E 1 test 통과.
  수정 충돌과 네트워크 실패 때 파일을 만들지 않고, 명시 클릭으로 내려받은 JSON을 계약으로
  재검증했다. 원본/정정·RPE 보고 시각/0/null·메모·시간대/시간 정의, 서버 쓰기 없음과
  revision 불변, 닫기 후 선택·상세 유지, 다른 탭 계정 변경 시 Blob 폐기를 확인했다.
  14개 viewport의 포커스·320px reflow도 확인했다.
- E2E 작성 중 Blob URL의 null 타입을 명시적으로 좁혔고, 첫 실행에서 계정 전환 후
  이전 세션이 폐기되어 정리용 GET이 401을 반환했다. 정리는 fixture Alice로 새 로그인한
  세션을 사용하고 Bob 소유권 검증 GET에도 해당 세션 헤더를 넣어 재실행을 통과했다.
- `pnpm check --maxWorkers=2` 통과: generated/format/lint/typecheck 및 74 files / 887 tests.
  M1-04aa에서 확인한 기본 병렬 실행의 기존 대용량 차트 시험 timeout을 피하기 위해 실행
  worker 수만 제한했다. 시험 timeout·설정·규칙은 변경하지 않았으며 기본 병렬 문제는 미해결이다.
- 전체 identity E2E 58 tests 통과.

  다운로드를 실행했다. 반환된 다운로드 파일을 읽어 format/count 및 원본·정정 반영 거리
  `0`/`null`, revision 1 보존을 확인했다. 닫기 후 선택 2개 유지와 opener 포커스 복귀를 확인했다.
  `batch-export-ready.png`를 직접 열어 화면을 확인했다. 첫 로그인 요청은 만료되어
  `invalid_request`였으며 계정 화면에서 새 OIDC 요청으로 로그인했다. 검증 소유 탭·서버·DB는 정리했다.
