# M1-04al · 세션 단계 단위 전환 확인

상태: 구현·검증 완료. S06·V2-F11의 단계 단위 전환 확인을 구현한다.

- 단계 시간은 초↔분, 거리는 m↔km로 표시·입력한다. 같은 차원 안에서만 전환한다.
- 전환 전후 값을 검토하고 확인하거나 취소한다. 표시 단위 변경은 계획 정본을 수정하지 않는다.
- 정본은 기존 durationSeconds/distanceMeters다. 단위 변경마다 왕복 저장하거나 반올림하지 않는다.
  미정 null·0·분수 값·반복 횟수와 다른 단계 필드를 보존한다.
- 입력 값 수정은 기존 초안 편집에 연결하고 별도 계획 미리보기·명시 저장을 유지한다.
- 단위 선택은 메모리에만 두며 API/DB schema·규칙·외부 출시 gate는 변경하지 않는다.
- 단계 ID를 유지한 순서 이동에서는 단위 선택을 보존한다. 검토 중 값·단계 위치·잠금 변경은
  전환 확인을 무효화한다. 키보드로 취소·확인할 수 있고 단위 선택으로 포커스를 돌려준다.
- 입력 중 잘못된 문자열은 화면과 오류 안내에 유지한다. 초안의 비유한 검증 상태로 계획
  미리보기를 막고 기존 저장 버전은 보존한다. 수정하거나 실행 취소하기 전에는 저장할 수 없다.
- 십진수 입력을 단위 배수와 함께 정본 숫자로 한 번 변환한다. 표시 근사값을 그대로 다시
  입력한 경우에도 기존 정본을 보존한다. 입력 크기와 단위별 정본 상한을 검사한다.
