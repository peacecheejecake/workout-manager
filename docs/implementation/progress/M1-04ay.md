# M1-04ay · 대시보드 실제 요약에서 기간별 활동 탐색

상태: 구현·검증 완료. S03 카드의 필터된 상세 탐색을 연결한다.

- 현재·직전 기간의 실제 수행 아래와 날짜별 표의 활동 조회 열에서 해당 활동 목록으로 이동한다.
  기존 계획 링크, 전체 활동 목록, 수치 셀과 미보고/0 의미를 보존한다.
- 공개 `DashboardLinks.activityRange` Host 함수는 from/toExclusive/timezone을 받는다.
  웹 Host가 URLSearchParams로 활동 목록 URL을 구성하며 모듈은 Next.js에 의존하지 않는다.
- 서버 응답에 적용된 날짜와 시간대를 전달한다. 계획 시간대가 요청 시간대와 다르면 계획 시간대를
  사용한다. 직전 기간은 previousFrom부터 현재 from 직전까지, 일별 종료는 다음 현지 달력 날짜다.
  DST 날짜를 24시간으로 환산하지 않는다.
- 시작 시각 미보고 활동은 날짜별 조회에 포함되지 않는다고 안내한다. 읽기 전용 탐색이며
  이전 활동 화면의 검색·선택·페이지·태그 조건을 새 탐색에 섞지 않는다.
