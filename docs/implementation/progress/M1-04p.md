# M1-04p · 활동 기록 상태 필터

상태: 구현·검증 완료. S07의 품질 필터 중 현재 저장된 기록으로 확인할 수 있는 상태를 구현한다.

## 범위와 의미

- `quality`: `missing_distance`, `missing_duration`, `missing_start`, `corrected` 중 하나를 선택한다.
- 미입력은 overlay를 적용한 effective 값이 null인 경우다. 거리·시간 0은 알려진 값이다.
  시간이 존재하면 `durationKind: unknown`이어도 시간 미입력이 아니다.
- 사용자 정정은 overlay에 명시적 정정 사유가 저장된 경우다. 원본 재수집의 revision 증가나
  최초 수동 활동 입력만으로 정정된 기록으로 분류하지 않는다. 같은 값의 명시적 정정은 포함한다.
- 기존 날짜·출처·종목·검색·불변 Block 연결 조건과 AND로 결합한다.
  시작 시각 미입력과 날짜 조건을 함께 적용하면 결과가 없는 것이 정확하다.
- URL 복원·초기화·선택 보존, 동일 SQL snapshot의 total/page, RLS·삭제 suppression을 유지한다.
- 품질 점수·생리학 평가·수집 완전성 판단과 전체 S07 완료는 포함하지 않는다.
