# M3-02a · HealthKit 운동 배치 수신 경계

상태: **로컬 수용 완료**. Phase `M3-02`의 일부이며 phase 독립 검토 전이다.

## 범위

- native bearer를 가진 소유자의 HealthKit 운동 변경을 최대 100개/64 KiB 배치로 받는다. 동의는 저장 transaction 안에서 다시 확인한다.
- 표본 UUID별 원본 head와 삭제 표식, 설치·배치 UUID별 receipt를 원자적으로 저장한다. 같은 내용의 배치 재전송은 원 ACK를 반환하고, 같은 ID의 다른 내용은 충돌로 거부한다. 삭제된 UUID의 늦은 추가는 복구하지 않는다.
- 동의 철회 시 원본과 배치 내용 해시를 지운다. 내용과 무관한 설치·배치 ID receipt만 재전송 차단용으로 보존한다. 계정 내보내기 v25와 계정 삭제에 새 원장을 포함한다.
- 이 작업은 원본 수신 경계다. 정본 Activity 연결, Garmin 중복 판단, native anchored collector·background delivery, 사용자 화면, 서명된 iPhone 전 과정을 완료로 보지 않는다.

## 검증 기록

- API 경계의 bearer·입력·오류 응답 4건, 계약 경계 24건이 로컬 Vitest에서 통과했다.
- 격리된 실제 PostgreSQL에서 집중 수신 시험 7건(제한 역할·tenant guard, 동시 중복, 수신↔철회 경합, 삭제 불복원, 내보내기·삭제)이 통과했다. 전체 통합 시험은 83파일 818건, 업그레이드 시험 1건이 통과했다. 최초 전체 실행의 34건 실패는 v25 export·migration 059·erasure wrapper를 반영하지 않은 기존 시험 기대값이었고, 해당 기대값을 갱신해 재실행했다. 철회 시 배치 내용 해시까지 지우는 수정 후 전체 재검사도 818건과 업그레이드 1건이 통과했다.
- `pnpm check:generated`, 전체 format·lint, typecheck 34/34, build 15/15, unit 4,191 통과·7 건너뜀이 통과했다. 첫 unit 실행은 sandbox의 로컬 OIDC fixture 바인딩 실패와 별도 worktree의 Python 가상환경 부재로 35건 실패·27건 건너뜀을 기록했다. 권한 있는 로컬 실행에서 `WORKOUT_PYTHON`을 지정해 전체 재실행한 결과다.
- `test:identity` 첫 실행은 철회 시 파생 해시 삭제 수정 전 중단했다. 수정 후 전체 실행은 290 통과·13 건너뜀·9 실패·3 미실행이었다. 실패 8건은 브라우저 수용 시험의 current export 버전 기대값이 v24로 남은 것이고, 1건은 이 별도 작업 트리에 Python fixture 경로가 없어 비공식 Garmin 경로가 꺼진 것이었다. 공통 기대값을 v25로 고치고 `WORKOUT_PYTHON`에 기존 가상환경을 지정한 집중 브라우저 5건이 통과했다. 최종 코드 기준 전체 재실행 두 회는 각각 **302 통과·13 건너뜀**이었다. 건너뛴 외부 지도 데이터 조건을 통과로 바꾸지 않는다.
- 실제 native HealthKit 제품 수집, 서명된 iPhone 및 서버 도달은 `not_executed`다.

## 배포 순서

Migration `059_healthkit_ingestion.sql` 적용 뒤 runtime에 `grantHealthKitIngestion`, 내보내기·삭제용 `grantOperations`를 재실행해야 한다. 이 단계가 끝나기 전에는 새 배치 경로를 활성 배포에서 사용하지 않는다.
