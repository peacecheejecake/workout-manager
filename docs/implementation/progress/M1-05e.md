# M1-05e · 상담 근거 저장·선택·검토 UI

상태: 구현·검증 완료. S10의 저장된 구조화 근거 검토를 M1-05c/d 위에 연결한다.

## 동작과 경계

- 명시한 1~90일 날짜 창·시간대로 저장한다. 저장된 전체 사용자 대화를 먼저 불러와야 하며,
  미전송 메시지는 포함하지 않는다. 날짜 불명 활동과 전체 계획 세션 완료 보고의 범위를 설명한다.
- 저장 당시 계획·제약·대화·활동·체크인·완료 보고와 당시 의존성만 표시한다. 현재 계획/관측으로
  본문을 채우지 않고, null·0·시간 정의·출처·관측 시간대와 조회 날짜를 구분한다.
- 인증 사용자/로그인 세션별 Zustand에는 날짜 입력과 고정된 명령만 둔다. 서버 응답은 별도
  Query cache 소유이며 영속화하지 않는다. 로그아웃/세션 변경은 초안·요청·cache 수명을 끝낸다.
- URL snapshot 선택·snapshotOffset은 상담 목록 offset과 분리한다. 상담 변경은 근거 선택을
  초기화하며 다른 상담 응답을 거부한다. 늦은 응답은 다른 상담으로 이동시키지 않는다.
- 결과 불명은 같은 key/body로 재확인한다. 저장 중에는 상담/근거 변경을 함께 잠근다. 409는
  표시된 전체 최신 대화의 명시 확인 후 새 저장이 필요하고, 413은 범위·한도 오류로 표시한다.
- 본문 재진입·재조회·focus/visibility/reconnect 검증 중 및 오류 상태에는 이전 내용을 숨긴다.
  회수된 목록 응답은 본문 표시를 막고 메모리 cache도 tombstone으로 교체한다. 이미 열린 화면에
  서버 push가 연결된 것은 아니므로 다른 창에서 삭제/동의를 바꾼 경우 새로 확인하도록 안내한다.
- AI 실행·전체 freshness·승인과 S05 계획 종류 해석은 범위 밖이다. 부모 및 외부 gate를 유지한다.

## 검증

- `pnpm check --maxWorkers=2`: 생성물·Prettier·ESLint·전체 consumer typecheck와
  147개 파일의 1,630개 unit/component 시험 통과.
- 이후 회수 metadata의 cache 교체를 보완하고 coaching 모듈 64개 시험·typecheck·lint를
  재검증했다. 로그인 세션 변경 시 근거 시간대 초안 제거도 기존 workspace 시험에 추가하여 통과했다.
- 최종 `API_ORIGIN=http://127.0.0.1:4301 pnpm build`: production 7개 task 통과.
- 실제 OIDC/API/격리 PostgreSQL E2E 6개 통과: 새 근거 UI 3개와 기존 상담 UI 3개.
  명시 저장·URL/reload·정정 전 내용 유지·원본 삭제 뒤 회수, 실제 커밋 뒤 응답 유실/동일 키 재확인,
  stale revision 409/명시 최신 기록 확인, 미전송 초안 보존·14개 viewport·320px reflow·키보드를 검증했다.
- Aside 실 브라우저에서 Next의 합성 계획/Phase 상담 생성→근거 저장·메시지 펼침,
  Vite에서 동일 근거 조회→별도 UTC 근거 저장, 합성 계정 AI 동의 철회 후 양 shell의 명시 재조회로
  본문 제거를 직접 확인했다. 원본 메시지는 상담에 남고 근거에는 저장된 사용자 메시지 1개만 있었다.
- Aside viewport screenshot을 열어 본문·목록·입력 배치를 확인했다. 로컬 증거는
  `2026-09-18_eiUnTC80fO2DgCzq/artifacts/evidence-next.png`, `evidence-vite-purged.png`다.
  locator screenshot은 Aside 오류가 나 page screenshot으로 확인했다. full-page 촬영은 반복된
  viewport가 이어져 검증 증거로 사용하지 않았다. 회수 사유는 별도 DOM snapshot으로 확인했다.
  Aside의 탭 활성화만으로 focus 재검증 완료를 주장하지 않는다. 자동 focus 경로는 component 시험,
  실 브라우저 회수는 명시 재조회 경로의 증거다. 소유한 탭과 API/Next/Vite·임시 DB는 종료했다.
- 서버/DB migration·저장 로직은 변경하지 않았다. 새 UI의 실제 DB 경로는 위 E2E로 검증했으며
  전체 DB integration을 별도로 재실행했다고 주장하지 않는다. Native/OS IME 검증은 포함하지 않는다.
- 95개 node DAG의 참조·비순환·증거 경로와 diff를 검사한다. 독립 Herdr split-pane 리뷰의
  base/tree·결과 및 수정 내역은 task 커밋 본문에 기록한다.
