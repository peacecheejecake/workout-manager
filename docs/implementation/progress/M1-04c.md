## 조회 의미

`GET /bff/v1/dashboard?anchor=YYYY-MM-DD&window=10&timezone=Asia/Seoul`.
window는 생략 시 10이며 3~90 정수만 허용한다. anchor는 조회 기준 현지 날짜다.
현재 계획이 있으면 계획 시간대, 없으면 query 시간대를 사용하며 `timezoneSource`로 구분한다.
입력한 anchor 날짜 자체를 UTC instant로 변환하지 않는다. 현재 창은 `[anchor-N+1, anchor+1)`,
비교 창은 그 직전 N개 날짜, 가까운 예정 세션은 기준일 다음 날부터 7개 날짜다.

활동 startedAt과 체크인 observedAt은 조회 시간대로 날짜를 투영한다. 체크인의 저장된
localDate/timezone은 바꾸지 않는다. 최신 체크인은 현재 창 안에서 관측 시각 내림차순·ID 순으로
선택한다. 시작 시각이 없는 활동은 날짜 창에서 제외하고 unplacedActivityCount에 별도 집계한다.

거리와 종류별 시간은 알려진 값만 합산하고 알려진 값이 없으면 null이다. count는 저장된 기록 수이며
수행/휴식의 완전한 관측을 뜻하지 않는다. source의 fit/fixture 및 정정 건수를 같이 제공한다.
현재 window와 일별 행은 같은 집계에서 만들어진다. 실제 RPE나 종합 회복 점수는 만들지 않는다.

계획 ID/version과 활동 정본 전체의 count + revision 합계(삭제 tombstone 포함), 체크인 collection head를
조회 시점 정보로 제공한다. Garmin OAuth 연결 시각을 활동 동기화 성공 시각으로 사용하지 않는다.
새 테이블·쓰기·권한 범위를 추가하지 않으며 기존 RLS/runtime SELECT와 계정 삭제 lifecycle gate를 쓴다.
