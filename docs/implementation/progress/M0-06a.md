# M0-06a · 공급자 조건 조사

확인일: 2026-09-16. 상태: 공개 문서·로컬 준비 조건 조사 완료.
FUT-04/05/07과 V2-F19, F25–F31의 외부 의존성을 구체화했다.

- [Garmin 권한 추적표](../research/garmin-prerequisites.md): 신청/심사/Activity/Health/평가/production과
  실제 payload 증빙을 분리했다. 접수 여부와 권한은 미확인이다. 표준 OIDC 앱 로그인과 provider OAuth도 구분한다.
- [경로 공급자 조건](../research/routing-prerequisites.md): renderer·tile·routing·고도·geocoding 경계,
  후보별 인증·운영·표시 조건과 한국 대표 지역 검증 입력을 정리했다.
- [Native 준비 조건](../research/native-prerequisites.md): HealthKit 권한·증분/삭제·background 제약과
  로컬 개발 도구 확인을 기록했다. 실기기·서명·실제 건강 자료 수집 증거는 없다.

확인 방법은 공개 공식 문서 조회와 비밀이 아닌 로컬 도구 존재 확인이다.
계정 신청·외부 연락·유료 서비스 등록·개인 건강 자료 수집은 수행하지 않았다.
문서 링크/JSON/DAG 의존성과 diff를 검사하고 Herdr split-pane 독립 리뷰를 수행한다.
검토 base/tree와 결과는 커밋 메시지에 기록한다. 문서 변경이므로 UI·DB 테스트 통과를 주장하지 않는다.

M0-06a 완료는 조사 산출물의 완료다. EXT-G·M0-06b·M0-06c·M1-06b·M2-01은 각각 별도 검증이 필요하며
공식 Garmin sync·한국 도보 경로 품질·HealthKit 실기기 기능이 완료됐다는 뜻이 아니다.
