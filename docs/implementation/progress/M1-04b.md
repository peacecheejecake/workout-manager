# M1-04b · 체크인 제품 UI

상태: 완료. M1-04a 이후 실제 체크인 API를 제품 화면에 연결한다.

관련: S12, FUT-02; 전체 S12·대시보드·활동 workbench 완료를 의미하지 않는다.

## 구현

- `/wellbeing` 인증 경계와 재사용 `@workout/modules-wellbeing` 모듈. Zustand는 사용자/세션별
  메모리 초안, TanStack Query는 서버 데이터, URL은 날짜/선택/페이지를 소유한다.
- 자기보고 작성·목록·정정 사유·삭제, null과 0 구분, 관측 시각·시간대·정의·출처 표시.
  기본 조회는 브라우저 시간대의 오늘을 포함한 30개 현지 날짜이고 조회는 1~90일로 제한한다.
- 저장 재시도는 고정 요청과 멱등키를 유지하고 revision 충돌은 초안을 보존한다.
  최신 원본 비교 후 사용자가 다시 정정 준비·저장을 선택한다. 자동 revision 치환은 없다.
- 서버 영수증과 현재 데이터를 구분하고 실제 원본을 다시 조회한다. 삭제된 상세의 예상된
  404를 성공 안내 대신 오류로 표시하지 않는다. 저장 이후 조회 실패는 따로 안내한다.
- URL·크기 변경 시 초안 유지, 계정/세션 변경 시 cache·초안 폐기와 늦은 응답 무시.
  명시적 초안 전환 확인과 beforeunload 경고, IME 조합 중 Enter 저장 방지.
- Host transport는 check-ins 경로만 추가 허용한다. 인접 이름/경로 탈출은 계속 거절한다.
- Turbo build의 API_ORIGIN을 환경 변수·캐시 입력으로 선언해 잘못된 API 주소가 재사용되지
  않게 했다. Next 개발 서버의 규칙 파일 자동 생성은 껐다. 기존 규칙 내용은 변경하지 않았다.

  전환 함수와 확인 버튼에 잠금을 적용하고 지연 409/503 회귀를 추가했다. 고정 질문과 척도
  앵커도 선택창 옆에 표시했다. 최종 재검토의 base/tree·결과는 커밋 본문에 기록한다.
