# M1-04v · 대시보드 카드 배치 편집·사용자별 보존

상태: 완료. S03의 기존 카드 layout edit와 반응형 배치 설정.

## 범위

- 기존 현재 계획·최신 체크인·기간별 요약·날짜별 거리 카드의 공통 ID와 순서를 보존한다.
- 명시 편집 모드에서만 손잡이·순서 이동 버튼·크기 선택을 제공한다.
- 편집 초안과 적용 배치를 분리하고 취소·기본 배치·명시 적용을 지원한다.
- mode별 크기와 공통 순서 allowlist만 사용자별 로컬 설정으로 저장한다.
  건강 데이터·API 응답·인증 값·미적용 편집 초안은 저장하지 않는다.
- breakpoint 전환 시 진행 제스처는 취소하고 편집 초안·다른 mode 설정을 보존한다.
- Orbit/영양/AI 카드 추가와 실제 훈련 부하 계산은 별도 범위다.

## 검증

- 고정 Widget ID 4개와 mode별 크기를 검증하는 scoped Zustand factory를 구현했다.
  늦은 hydration이 편집을 덮어쓰지 않으며 strict allowlist serializer만 저장한다.
- 사용자·세션 lifetime 내부 provider가 SSR 기본 배치와 viewport mode를 연결한다.
  사용자별 key에 적용된 배치만 기록하고 저장 권한/용량 오류는 화면 내 상태로 표시한다.
- `pnpm check` 최종 통합 59 files / 732 tests, production build 7 tasks 통과.
  store 17·storage provider 7·편집 UI 6 tests에서 독립 인스턴스, 형식 손상,
  명시 적용/취소/초기화, mode별 크기, viewport 전환·DOM/focus 보존을 검증했다.
- 실제 OIDC·격리 PostgreSQL 초기 배치 E2E 4 tests 통과 (11.3초).
  순서/너비 적용·reload·취소·초기화, drag/resize Escape·geometry 취소,
