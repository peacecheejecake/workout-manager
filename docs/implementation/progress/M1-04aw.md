# M1-04aw · 세션별 연결 실제 집계·거리 비교

상태: 구현·검증 완료. S05 실제 수행·차이 열.

- `GET /bff/v1/plans/versions/:planVersionId/session-actuals`는 소유한 불변 계획의 모든 세션을
  최대 1,000개 집계로 반환한다. 현재 활동의 명시적 planVersionId + sessionId 연결만 포함한다.
  활동 목록 페이지나 날짜 범위에 한정하지 않으며 날짜가 같다는 이유로 연결하지 않는다.
- 단일 SQL snapshot에서 원본/정정·삭제 제외 현재 활동, 저장 목표·현재 head·삭제 포함
  canonical count/revisionSum을 읽는다. 외부 tenant·없는 버전은 같은 404로 처리한다.
- null/0·알려진/미보고 개수와 시간 정의를 보존한다. 일부 거리 미보고가 있으면 부분 합계를
  표시하며 확정 차이는 계산하지 않는다. 수집 완전성은 unknown이고 연결 없음은 실제 0이 아니다.
- 거리 전체가 알려져 있을 때만 저장된 단일 목표 차이 또는 목표 범위 미만/범위 안/초과를 표시한다.
  범위 중간값을 만들지 않는다. 계획 시간의 정의가 없어 시간 차이는 제공하지 않는다.
- 계획 표의 `actual`·`comparison` 열은 표시/고정 URL을 재사용한다. 초안 목표를 수정해도
  비교는 저장 목표 기준이다. 새 ID의 세션은 저장 전으로 표시하고 과거 링크를 새 head로 이월하지 않는다.
- 조회 중·실패·버전/세션/목표 불일치에서는 오래된 결과를 현재처럼 표시하지 않는다. 다시 확인은
  초안·선택을 보존한다. 인증 사용자/세션/계획 버전별 쿼리와 AbortSignal로 수명을 격리한다.
- 완료 보고는 기존 독립 열로 유지한다. 이 집계는 완료·미수행·이행률을 만들지 않는다.
