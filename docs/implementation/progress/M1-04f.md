# M1-04f · 활동 목록 제품 UI

상태: 완료. S07의 조회 기능을 실제 API에 연결한다.

## 범위

- `/activities`는 검색·기간·종목·출처·정렬·페이지·표/카드·선택 ID를 URL로 관리한다.
- 날짜 필터는 요청한 시간대의 현지 날짜 기준이다. 날짜가 없는 활동을 임의 배정하지 않는다.
- 목록의 total은 적용한 필터 결과다. 다른 조건을 요청할 때 이전 조건의 행을 표시하지 않는다.
- 같은 조건의 재조회 실패는 마지막 조회 결과임을 명시한다. 조회 시각은 제공자 동기화 시각이 아니다.
- 선택 ID의 상세는 목록과 독립적으로 조회한다. 페이지 밖이나 필터와 불일치하는 선택도 유지한다.
  원본·정정 적용값·단위·시간 정의·출처를 읽기 전용으로 확인한다.
- 기존 FIT 파일 가져오기·정정·로컬 삭제는 `/activities/import`로 경로를 분리해 보존한다.
  목록에서 `FIT 가져오기·정정` 링크로 접근한다. 기존 작업의 저장/충돌 계약을 변경하지 않는다.
- 새 조회 화면은 URL과 TanStack Query가 상태를 소유한다. 사용자/세션 cache를 분리하며
  건강 기록을 browser storage에 저장하지 않는다.

## 남은 범위

이번 task는 S07 전체 또는 S09 전체 완료가 아니다. 수동 기록, 태그/주기/품질 필터,
대량 동작, 실제 구간·GPS·영향·미디어 상세는 후속 작업이다. 상세를 아직 수집하지 않은 활동에
GPS가 없다고 단정하지 않는다. 지도·OS IME·실기기·공식 Garmin gate를 유지한다.
