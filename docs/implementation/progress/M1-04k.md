# M1-04k · 활동 상세 로컬 삭제 UI

상태: 완료. S07·V2-F12·V2-A20의 단일 선택 활동 삭제를 연결한다.

## 범위

- 실제 선택 상세의 최신 revision으로 삭제 확인을 시작한다. 제목·출처·삭제 범위와
  공급자 원본 삭제가 아님을 표시한다. 로컬 숨김·재수집 억제와 계정 완전 삭제를 구분한다.
- 확인 대상 ID와 revision을 고정하고, 선택·활동 변경 시 미제출 확인을 무효화한다.
- 서버 성공 이후에만 선택·목록·총건수를 갱신한다. 충돌은 최신 기록을 검토하고 다시 확인한다.
- 응답 불명확 시 성공으로 표시하지 않고 동일 삭제 명령으로 수동 재시도한다.
- 계정·세션과 pending 명령의 수명, 키보드 취소/focus, 320px 화면을 검증한다.
- 기존 API·revision 검사·삭제 suppression 저장을 사용한다. 대량 선택/삭제와 provider 삭제는 이 slice가 아니다.
