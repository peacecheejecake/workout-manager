# M1-05i2b2b · 비프로덕션 fixture 연결·실행 E2E

상태: **completed**. 선행 M1-05i2b2a 완료. 이 slice로 M1-05i2b2, M1-05i2b,
M1-05i2, M1-05i의 명시된 결정론 실행 범위를 함께 수용한다.

`createConfiguredApi`는 개발·테스트 환경에서 `COACHING_FIXTURE_ENABLED=true`와
`COACHING_FIXTURE_ID=synthetic-v1`를 함께 지정할 때만 코치 실행 API를 연결한다.
프로덕션에서 fixture 활성화를 요청하면 서버 시작 전에 거부한다. 별도 `apps/worker`의
one-shot CLI는 명시적 athlete ID와 전용 `workout_coaching_worker` DB 역할을 요구한다.
일반 API 요청은 worker를 직접 실행하지 않는다.

실행 출력은 현재 AI 동의·근거·대화·계획과 core-v2 의존성·정책을 tenant 트랜잭션에서
재검사한 후에만 조회한다. 응답은 `untrusted_fixture`·`unvalidated`를 명시하고,
회수·취소·stale 출력은 `OUTPUT_NOT_FOUND`로 숨긴다. 사용자 취소 후 재실행되는
outbox 이벤트도 출력을 만들지 않는다. 이 경로는 실제 모델, 검증된 Decision/Proposal,
계획 승인 기능을 제공하지 않는다.

검증: 임시 PostgreSQL integration 24파일·205개, worker 구성 unit 6개,
20개 패키지 typecheck, web production build, 실제 OIDC·same-origin API·Chromium·
전용 worker CLI·임시 PostgreSQL E2E 2개(분석 조회와 queued 취소), 변경 파일
