# M1-04ar · 계획 시나리오 A/B/C 저장·비교·적용

상태: 구현·검증 완료. 제품 명세 §5.2의 계획 시나리오는 세션 강도 A/B/C 라벨과 별개다.

- 저장된 기준 계획 버전마다 A/B/C 대안을 독립 저장한다. 분기 생성·수정은 현재 계획을 바꾸지 않는다.
- 대안 수정본은 불변이며 조회·비교할 수 있다. 현재 계획 적용은 별도 미리보기와 명시 확인을 요구한다.
- 적용 명령은 대안 수정번호·현재 계획 버전·완료 원장 버전을 고정한다. 자동 병합하지 않는다.
- 현재 계획 잠금과 사용자 완료 일정 보호를 공통 저장 경로에서 검사한다. 활동 연결로 완료를 추정하지 않는다.
- 분기의 잠금 해제도 별도 저장이 필요하며 현재 계획 잠금을 우회하지 않는다.
- 적용 출처·계획 이력·outbox·receipt를 같은 거래에 기록한다. 응답 유실 후 동일 명령 재시도는 원래 결과를 반환한다.
- 계정 export v4에 대안·수정·적용 출처를 포함하고 v2/v3 읽기를 보존한다. 삭제·백업 복원에도 새 테이블을 포함한다.
