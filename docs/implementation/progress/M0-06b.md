# M0-06b · UI·지도 호환성 spike

확인일: 2026-09-16. 상태: **진행 중**. UI 실행 기반을 구현했으며 지도 coverage gate는 미확인이다.
M1-04 의존성을 아직 해제하지 않는다. FUT-07 및 복합 UI·IME·접근성 검증에 해당한다.

## 구현 범위

`@workout/ui-spike/workspace`를 Next와 Vite의 `/ui-spike`, Storybook에서 공유한다.
사용자가 검증 도구를 열 때 지도·데이터·상호작용 패널을 각각 lazy load한다.
자료는 합성이며 서버·사용자 건강 자료와 연결하지 않는다. 입력은 컴포넌트 수명의 메모리에만 존재한다.
기존 제품의 Zustand draft / Query server cache 소유권은 바꾸지 않는다.

| 후보                   | 고정 버전 | 실제 실행 범위                                                          |
| ---------------------- | --------- | ----------------------------------------------------------------------- |
| MapLibre GL JS         | 6.9.1     | 동일 origin ESM worker, GeoJSON 선 렌더링·해제·재생성, WebGL2 실패 대안 |
| ECharts                | 6.1.0     | SVG 막대 차트, 확대/구간 제어, 표 선택 연계, resize/dispose             |

[설치 패키지 기록](../research/ui-spike-packages.json)은 direct dependency의 버전·peer 조건·라이선스와
배포된 LICENSE 파일 해시를 기록한다. MapLibre는 BSD-3-Clause, ECharts는 Apache-2.0,
나머지 표의 후보는 MIT다. 전이 의존성 전체와 유료 확장의 라이선스 검토 완료를 뜻하지 않는다.
MapLibre 6.10.0은 설치 시 기존 minimumReleaseAge 조건을 충족하지 않아 6.9.1을 선택했다.

## 빌드와 경계

MapLibre 6의 worker와 shared ESM 파일을 각 shell의 `public/dist/maplibre`에 함께 복사한다.
LICENSE도 복사하며 생성 파일은 Git에 포함하지 않는다. Turbo build output에 해당 경로를 포함한다.
Next 해당 route 및 Vite production preview는 `worker-src 'self'`와 `connect-src 'self'`로 실행한다.
이는 worker/network 호환성 검증이며 전체 앱의 script nonce 등 CSP 강화 완료를 뜻하지 않는다.
[MapLibre 문서](https://maplibre.org/maplibre-gl-js/docs/)와
[v6 migration](https://maplibre.org/maplibre-gl-js/docs/guides/v5-to-v6-migration-guide/)의 ESM·WebGL2 조건을 따른다.

Vite production lazy chunk는 지도 약 1,014 kB / gzip 276 kB, 데이터 패널 약 955 kB / gzip 315 kB다.
500 kB 경고가 남는다. lazy load는 첫 진입 비용을 분리하지만 제품 성능 budget 통과 증거는 아니다.
1,000행은 bounded 기능 검증이며 가상화·저사양 기기 성능을 검증하지 않았다.

## 브라우저 확인과 남은 검증

자동화는 실제 라이브러리를 사용한다. MapLibre 시험은 Chromium software WebGL이므로 물리 GPU 증거가 아니다.
320/767/768/1279/1280px resize에서 편집기 focus·입력·합성 composition event를 확인한다.
정렬/취소·panel resize·초안 보존, worker 렌더링과 unmount, WebGL 미지원 대안을 확인한다.
Next/Vite 요청에서 외부 tile 요청이 없음을 검사한다.

Aside 실 브라우저에서 두 shell의 패널을 열고 표 정렬, 한글 문자열과 literal script 문자열 편집,
JSON 확인, 순서 변경, 메모 및 separator 키보드 조절, 지도 해제/재생성을 확인했다.
좁은 화면에서 SVG가 가로로 넘치는 문제와 resizable Group의 inline 100% 높이로 다음 영역이 겹치는
문제를 발견해 수정했다. 자동 회귀에 reflow 및 영역 간 비겹침 검사를 포함했다.
수정된 Next production 화면을 Aside에서 다시 열어 separator 조절 후 메모 유지와 지도 영역 분리를
스크린샷으로 확인했다. 스크린샷은 Aside 로컬 세션의 `artifacts/ui-spike-final-next.png`에 보관한다.
OS 한글 IME 조합, 실제 손가락 drag, WKWebView/HealthKit 실기기 시험은 실행하지 않았다.
Storybook은 build 검증 대상이며 별도 browser interaction suite는 아직 없다.

## 경로 coverage

[실행 결과](../research/routing-sample-results.json): 공개 합성 한국 도심·하천 횡단 2건과 음성 대조군
1건을 foot endpoint에 직렬 요청했다. 1.1초 간격, timeout/응답 크기 상한, 재시도 없음이다.
세 건 모두 HTTP 응답 전에 실패했다. engine/graph version, 거리·geometry와 실제 도보 접근성은 미확인이다.
실행 권한 확장 상태에서도 응답이 없었지만 DNS/TLS/망/공급자 중 원인을 식별하지 못했으므로 공급자 장애로 단정하지 않는다.

`node scripts/probe-routing.mjs`는 기본 실행에서 네트워크를 사용하지 않는다.
`--execute`를 명시한 수동 실행만 고정 합성 3건을 보내며 CI 실행을 거절한다.
결과를 다시 생성할 때 기존 보고서는 교체된다. 사용자 GPS·토큰 입력이나 자동 반복 호출은 제공하지 않는다.
현재 지도는 합성 선이며 실제 도로·보행 경로를 표시하지 않는다.

M0-06b 완료 전 실제 routing 응답·한국 표본 coverage/제약 검토, 나머지 후보 adapter 범위와
OS IME·touch·성능·라이선스 검토를 마무리해야 한다. 실패를 통과로 바꾸거나 task graph gate를 완화하지 않는다.

## 검증 기록

정적 검사(생성물·Prettier·ESLint·TypeScript), Next/Vite/Storybook production build를 통과했다.
unit/component 322개, 두 shell Playwright 18개, OIDC·계획·활동 API/DB E2E 4개,
tooling fixture E2E 4개를 통과했다. 처음 unit 실행은 sandbox loopback listen 제한으로 OIDC 8건이
실패했으며, 로컬 서버 실행 권한으로 다시 실행해 전체 통과를 확인했다.
최종 실행 결과와 Herdr 독립 리뷰의 base/tree는 이 작업의 커밋 메시지에 기록한다.
리뷰는 변경 코드·설정·보고서 전체를 대상으로 하며 규칙 파일은 수정하지 않는다.
첫 리뷰의 P2 지적은 굵게 버튼의 활성 상태 누락이었다. 편집기 transaction/selection을 구독해
`aria-pressed`와 선택 표시를 연결하고 토글·커서 이동·undo·단축키 검증을 추가했다.
