# M1-04ag · 선택 기간 계획·실제 요약과 주요 세션

상태: 완료. S04 §5.2의 선택 기간 집계·핵심 세션을 읽기 전용으로 연결했다.

## 범위와 의미

- 소유한 불변 계획 version + period ID로 기간 전체 요약을 조회한다. 계획은 해당 기간과
  하위 Block의 세션을 한 번씩 집계하고 주요 세션은 명시 priority high만 사용한다.
- 실제는 선택 기간 시간대의 시작일 포함·종료일 미포함 날짜 범위에 시작한 활성 정본의
  현재 관측값이다. 사용자 정정·삭제를 반영하며 명시 계획 연결·계획 이행과 구별한다.
- 거리 null/0·시간 정의(timer/elapsed/moving/unknown)별 알려진 합계와 미정 개수를 유지한다.
  수집 완전성은 unknown이고 이행률·확정 증감·휴식·생리적 부하를 추정하지 않는다.
- 단일 DB statement snapshot에서 계획·현재 head·actual 합계·전체 activity revision 표식을
  읽는다. 과거 계획 버전에서도 actual은 현재 관측이며 과거 actual 복원으로 표현하지 않는다.
- 전체 계정의 시작 시각 미정 활동 수는 기간 미배정으로 별도 표시한다. year 0000 기간의
  실제 집계는 unsupported_calendar로 표시하고 임의 AD 날짜로 바꾸지 않는다.
- UI는 저장된 계획 기준임을 명시하고 초안·실제 활동을 변경하지 않는다. 계정/세션/version/
  period별 조회 캐시·응답 식별자 검사·취소·오류 재시도를 적용한다.
- 기간 타임라인·대회·시나리오 branch·기간 이동 확인은 별도 미완료 범위다.

- 계약 6개, API 8개, 신규 컴포넌트 6개 시험 통과. owner 경계·동일 404·200자 기간 ID,
  응답 식별자·계정/기간 변경 중 늦은 응답·오류 재시도·주요 세션 선택을 확인했다.

  계정 격리·전체 기간 집계·사용자 정정·삭제·시작 시각 null 전환·과거 계획/현재 actual·
  year 0000 미지원과 legacy 불변을 검증했다. 단일 statement로 집계의 관측 경계를 유지한다.

  503 재시도·14 generated viewport·초안/포커스·조회 중 쓰기 없음·reload를 확인했다.
