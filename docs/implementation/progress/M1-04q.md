# M1-04q · 계획 표 정렬·열 표시

상태: 구현·검증 완료. S05 표의 정렬과 열 표시 설정을 구현한다.

## 범위

- 날짜·제목·거리·시간 양방향 정렬. 거리·시간 null은 양방향 모두 뒤에 두고 0과 구분한다.
  동률은 세션 ID로 안정 정렬한다. 계획 배열은 변경하지 않는다.
- 날짜·제목은 유지하고 Block·목적·거리·시간·목표 RPE·메모를 선택 표시한다.
- URL `plannedSort`·`plannedColumns`를 원본으로 사용한다. 보기/화면 전환·새로고침에도 복원한다.
  잘못된 값은 알림과 기본 표시로 복구하며 계획 저장은 수행하지 않는다.
- 달력·표의 선택과 상위 편집기 초안을 유지한다. 키보드 정렬·aria-sort·320px reflow를 검증한다.
- column pinning·범위 선택·가상화·DnD·Orbit와 전체 S05 완료는 별도 작업이다.
