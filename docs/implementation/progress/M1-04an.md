# M1-04an · 세션 페이스·심박 목표 입력

상태: 완료. S06·V2-F11의 사용자 입력 세션 목표를 계획 초안·저장·이력에 연결했다.

- `paceTarget?: { minSecondsPerKm, maxSecondsPerKm } | null`과
  `heartRateTarget?: { minBpm, maxBpm } | null`을 선택적으로 확장한다.
- 두 경계가 같으면 단일 목표, 다르면 범위다. 페이스는 빠른 경계·느린 경계와 초/km를 명시한다.
- 페이스는 유한한 양수·최대 86,400초/km, 심박은 1~1,000bpm 정수이며 작은 경계가 큰 경계를
  넘을 수 없다. 상한은 기술적인 입력 한도이며 건강상 권장 범위나 타당성 판정이 아니다.
- 필드 부재는 기존 snapshot·receipt에 그대로 유지하고 명시적으로 지우면 null로 기록한다.
- 기존 intensity 잠금은 두 목표에도 적용한다. 잠금 해제와 보호 값 변경은 별도 저장이어야 한다.
- 목표는 실제 관측·달성 판정·추천과 별도다. 단계별 목표나 생리학 모델은 이 task에 포함하지 않는다.

저장 전 전체 비교와 선택한 저장 세션 상세에도 단위를 표시한다. 잘못된 경계·부분 입력은
초안을 유지하면서 미리보기·저장을 막는다. 복제·기간 이동·실행 취소는 목표를 보존한다.
