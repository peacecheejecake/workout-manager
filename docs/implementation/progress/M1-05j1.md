# M1-05j1 · 훈련 후보 계약·순수 diff/검증

상태: **completed**. 선행 M1-05i 완료. M1-05j의 첫 단계로,
running-core-v2 훈련 범위에 한해 Decision/Proposal/Candidate의 versioned 계약과
고정 PlanSnapshot 대비 변경 초안의 결정론적 비교·검증을 구현했다.

순수 계산은 세션/기간별 before·after를 안정된 순서로 반환하고 목표 시간(초)·거리(미터)의
정확값·범위·미확인을 분리한다. 미확인 목표가 있으면 전체 delta는 계산하지 않는다.
잠금, 사용자가 완료한 세션의 일정, 과거 세션/기간 수정, 기간의 운동 불가 날짜·가용 시간,
변경 없음과 불완전한 목표를 error/warning/unknown으로 분류한다. 검증 기준 현지 날짜도
후보 본문에 포함한다. 현재 계획 버전이 다르거나 입력이 잘못되면 결과를 만들지 않는다.

후보 초안은 서버 저장 전 계산 결과다. 코치 실행의 `untrusted_fixture` 출력은
구조화된 변경 명령이 아니므로 이 단계에서 후보로 승격하지 않는다. 검증 결과의
`checked`도 승인 허가를 뜻하지 않는다. tenant 불변 저장·서버 digest·동의 철회/삭제
수명주기는 M1-05j2, 구조화 fixture와 조회 API·실DB E2E는 M1-05j3,
명시 승인 transaction은 M1-05k에서 수행한다.

계약·순수 로직 단위 시험 11개와 두 패키지 typecheck/build, ESLint·Prettier를
통과했다. 전체 workspace 검증, DAG·diff 검사 및 Herdr split-pane 리뷰의 정확한
base/tree identity는 task 커밋 본문에 기록한다.
