## P5 지도 제스처

`tests/identity/map-gesture-escape.spec.ts`는 Next·Vite의 `/courses/new`에서 실제 renderer canvas 위 일반 wheel 두 번 뒤 문서 scrollY 증가, Tab·Shift+Tab으로 지도 밖의 보이는 포커스 가능한 컨트롤 도달을 단언한다. 최초 시험의 "Tab 한 번" 가정은 지도 내부 포커스 대상이 여러 개여서 두 shell 모두 실패했다. 유한 이동과 포커스 가능성 단언을 강화한 최종 판은 Chromium **2/2 통과**했다. `cooperativeGestures: false` 변이로 두 shell을 다시 빌드하자 둘 다 `scrollY` 단언에서 실패했다. 원본 `true`를 복구해 재빌드한 뒤 **2/2 재통과**했다. 직접 Chrome 관찰에서도 Next 지도 위 일반 스크롤 뒤 페이지 위치가 이동했다. 이 시험은 Chromium wheel·키 입력이며 물리 touch·OS IME 검증이 아니다. `P5-gesture-escape`는 이 범위에서 `not_executed`에서 `passed`로 판정했다. `R-touch-ime`는 `not_executed`를 유지한다.

Aside CLI `1.26.916.1741`은 설치됐지만 REPL 접속에서 `fetch failed`로 브라우저 앱에 연결되지 않았다. Chrome의 첫 로컬 OIDC 로그인 클릭은 자동 승인 검토가 특정 계정 승인 부재를 이유로 거절했다. 우회하지 않고 사용자에게 물었으며, 사용자가 **로컬 Alice 로그인**을 명시적으로 승인한 뒤 같은 fixture flow로 Chrome 관찰을 마쳤다. 실제 Zitadel 계정은 사용하지 않았다.

검사: `pnpm install --frozen-lockfile`, `check:generated`, 전체 lint·format, typecheck 34/34(캐시 사용), 변이 빌드·복구 빌드 각각 15/15, 전체 단위 339파일·4,104시험, 격리 PostgreSQL 통합 81파일·804시험이 통과했다. 전체 identity는 격리 fixture를 새로 띄워 **2회 각각 297 passed, 11 skipped**였다. 조건부 11건은 실엔진·운영 공급자 조건이 없어 실행하지 않았다. 기본 sandbox의 첫 install은 registry DNS, 첫 전체 단위는 loopback 제한으로 실패했고, 허용된 실행 환경의 동일 검사에서는 위 결과로 통과했다. 임시 변이 소스는 원본으로 복구했고 `git diff --check`도 통과했다.

실기기 touch·IME와 실제 background wake는 이 노드의 브라우저 시험으로 대체하지 않는다. 매트릭스는 110행 중 passed 93, partial 13, failed 1, not_executed 3이다. 이 노드의 완료는 M2-01k 부모나 M0-06b의 외부 gate 완료를 뜻하지 않는다.
