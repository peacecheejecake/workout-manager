# M0-07a · 로컬 FIT batch

기준일: 2026-09-16. 상태: **완료** — 구현·로컬 검증·독립 리뷰 완료.

Codex native agent가 Python 구현·테스트를 맡고 root가 의존성·CI·문서와 통합 검증을 담당했다.

## 구현과 실제 검증

- `workout-manager convert`: 파일/디렉터리, 재귀 탐색, 명시적 출력 경로, CSV/Parquet 선택.
- FIT CRC 검증, 파일당 64 MiB/스트림 128개/definition 포함 메시지 100만 상한, 파일별 실패 격리, 출력 디렉터리 파일 잠금.
- record/lap/session을 실제 포맷으로 저장. 원본 경로별 출력 및 source/output SHA-256 manifest.
- `--resume`은 성공·원본/출력 해시 일치 시에만 skip. 손상·부분 출력 복구는 명시적 overwrite가 필요하다.
- 개별 파일은 staging 후 교체하며 manifest도 원자적으로 교체한다. 세 출력 전체가 하나의 filesystem
  transaction은 아니다. 중간 실패는 성공 항목으로 기록하지 않으며 재실행으로 복구한다.
- 기존 `scripts/fitparse.py` 진입점 보존, third-party fitparse import shadowing 및 가짜 Parquet 수정.
- Ruff check/format 통과. pytest 30개 통과: synthetic CRC FIT, CSV/Parquet roundtrip, CLI/wrapper
  subprocess, resume·손상·충돌·크기 상한·출력 publication 실패·복구 검증.
  연결된 빈 스트림, definition flood, 잘못된 developer metadata의 파일별 실패 격리도 검증했다.
- GitHub Actions Python job 추가. 원격 CI 실행은 아직 하지 않았다.

## 범위

macOS/Linux의 POSIX 잠금을 사용한다. 다운로드·provider 인증·canonical activity 적재는 구현하지 않았다.
manifest provider/activity ID는 null이며 추정하지 않는다. 개인 FIT/GPS는 검증·커밋에 사용하지 않았다.
공식 다운로드 M0-07b는 EXT-G 권한 확보가 추가로 필요하다.
