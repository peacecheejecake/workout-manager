# M1-04av · 계획 표 사용자 완료 보고 상태

상태: 구현·검증 완료. S05 표 상태 열의 자기보고 범위.

- 표의 `완료 보고` 열은 사용자의 완료 확인·철회·확인 기록 없음·저장 전 세션을 구분한다.
  실제 활동 연결·시간 경과·계획 목표로 완료를 추정하지 않는다. 미보고나 철회는 미수행 판정이 아니다.
- 기존 현재 계획 완료 원장을 재사용하며 추가 API/DB 쓰기를 만들지 않는다. 보고가 참조하는
  과거 계획 버전과 현재 조회 버전을 구분한다. 같은 stable session ID의 보고는 유지하지만,
  새 ID로 복제한 초안에는 보고가 전이되지 않는다.
- 조회 중·실패·현재 계획/완료 목록 버전 불일치를 별도 상태로 표시하고 오래된 확인을 현재 결과처럼
  표시하지 않는다. 초안 기준 버전이 현재 head와 다를 때도 불일치로 표시한다.
- 기존 다시 확인으로 복구하며 초안 메모·세션 선택을 보존한다. 표시/고정은 기존 URL 설정에
  `completion` 열을 추가한다. 과거에 지정한 열 목록은 그대로 존중하고 기본 목록에만 추가한다.

## 남은 범위

S05의 실제 수행·거리 차이 열은 별도 세션 집계 조회가 필요하다. 기존 페이지 목록이나 날짜 집계를
명시적 세션 연결 합계로 대신하지 않는다. 다음 조회는 owner + 불변 planVersionId + sessionId 연결,
삭제/정정 revision, 0/null/부분 합계와 시간 정의를 보존해야 한다.

규칙·완료 원장/이동 보호·외부 출시 gate는 변경하지 않는다. Herdr 독립 리뷰의 base/tree·완료 판정은
task 커밋 본문에 기록한다.
