# M1-04o · Planner 달력·표 동시 보기와 반응형 전환

상태: 구현·검증 완료. S05·V2-F09와 반응형 명세의 calendar/table 동시 보기와 요청 보기 복원을 구현한다.

## 범위

- 달력과 표는 동일 계획/초안·조회 범위·선택을 사용한다. 넓은 영역에서 40:60으로 배치한다.
- viewport와 실제 모듈 container 폭을 구분하고 생성된 반응형 상수를 사용한다.
  좁은 영역에서는 한 보기를 사용하면서 split 요청과 선택을 보존하고, 다시 넓어지면 복원한다.
- editor DOM·Zustand 초안은 보기 전환보다 위에 유지하고, 사라지는 pane의 focus는
  동일 세션 또는 안정적인 컨트롤로 옮긴다. 숨긴 중복 컨트롤을 tab 순서에 남기지 않는다.
- 화면 폭이나 보기 변경은 저장·실제 활동 변경·계획 연결을 수행하지 않는다.
- DnD·고급 표 기능·Orbit와 전체 S05 완료는 별도 작업이다.
