# Garmin 공식 연동 후속 계획 · 2026-09-27

상태: **Web MVP 활성 작업 그래프 밖으로 이관. 구현·공급자 검증 미완료.**
사용자는 2026-09-27에 공식 Garmin adapter 구현을 후속 작업으로 미루고, 현재 구현된
소유자 한정 비공식 adapter를 이용해 나머지 개발을 진행하기로 결정했다. 이 결정은
[기존 임시 gate 결정](garmin-temporary-gate.md)의 "공식 연동은 Web MVP 필수" 부분과
2026-09-26의 `EXT-G` 유지 결정을 **현재 출시 범위에 한해 대체**한다. 기존 결정과
검증 기록은 삭제하거나 통과로 다시 쓰지 않는다.

## 현재 Web MVP 범위

- 활성 [작업 그래프](../task-graph.json)의 `G2`는 `M2-06`의 전체 Web 업무·보안·삭제·운영
  내부 준비 판정이다. `G2-PUBLIC`은 여기에 `EXT-HOSTING`을 더 요구한다. 공식 Garmin
  권한·adapter·실제 공급자 출시 검증은 두 gate의 선행 조건이 아니다. 원래 공식 연동 포함
  Web MVP의 완료를 주장하지 않는다.
- 완료된 `M1-06b-tmp`는 `python-garminconnect`의 문서화되지 않은 Connect 경로를 쓰는
  **비공식**, 소유자 한 명 전용, 기본 꺼짐 기능이다. 이후 구현·통합 시험은 이 adapter가
  제공하는 수집 interface와 합성 fixture를 사용할 수 있다. 공식 OAuth, 공식 권한,
  일반 사용자 자동 수집의 증거로 쓰지 않는다.
- 이 선택 기능을 실제 소유자 계정에서 켜려면 사용자가 앱에서 직접 연결하고,
  수집·중복·삭제 억제·오류 복구를 별도 실행해 기록한다. 현재 그 실제 계정 실행은
  `not_executed`다. 실제 검증 전에는 fixture 시험을 실연동 통과로 표시하지 않는다.
  비공식 경로의 제한·기본 꺼짐·비밀 보호·철회·복원 조건은
  [임시 gate](garmin-temporary-gate.md)와 [운영 안내](../garmin-setup.md)를 유지한다.
- 로컬 FIT 가져오기는 계속 별개이며 자동 동기화가 아니다. 공식·비공식·FIT 활동의
  provenance와 삭제 억제를 구분한다.

## 활성 그래프에서 이관한 작업

| 이전 노드                    | 후속 선행 조건·완료 증거                                                                                                                                  |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `EXT-G` 공식 권한            | Garmin Connect Developer Program의 실제 승인, 파트너 명세·entitlement·검증 계정. 조사나 fixture는 승인 증거가 아니다.                                     |
| `M0-07b` 허가된 FIT 다운로드 | `M0-07a`와 `EXT-G` 뒤 허가된 출처의 실제 파일, resume/manifest, 실패·재시도·무결성 검증. 로컬 FIT import와 구분한다.                                      |
| `M1-06b` 공식 adapter        | `M1-03`, `M1-06c`, `EXT-G` 뒤 발급된 앱 자격 증명으로 공식 로그인·동의·실제 token/권한·철회, Activity/Health 응답, 자동 수집과 정본·화면 반영을 검증한다. |
| `M2-07` 공식 연동 출시 검증  | `M2-06`과 `M1-06b` 뒤 실제 Garmin 수집을 앱 전체에 연결해 동의·실패 복구·공급자 회귀·tenant/삭제·출처를 검증한다.                                         |

공식 작업을 재개할 때 최신 파트너 명세·권한·자격 증명·법적/운영 조건을 다시 확인하고,
별도 활성 노드와 phase 브랜치로 가져온다. 현재 비공식 adapter를 공식 adapter로 이름만
바꾸거나 `M1-06b-tmp`의 합성 검증을 이 표의 완료 증거로 승격하지 않는다. 공식 경로가
착지할 때 [교체·은퇴 절차](../garmin-setup.md)를 실행하고 provider 간 중복 판정을
확인한다.

## 남는 출시 구분

`G2`가 나중에 통과하더라도 결과는 **공식 Garmin을 제외한 Web MVP의 내부 준비 판정**이다.
`G2-PUBLIC`에 필요한 `EXT-HOSTING`의 실제 배포 증거는 별도로 남는다. 비공식 연결을
소유자 외 사용자에게 제공하거나 공식 자동 연동이라고 표시하는 별도 범위 변경은 이
결정에 포함되지 않는다. 공개 배포의 HTTPS·TLS·secret manager·실제 OIDC 검증은
`EXT-HOSTING`에 남으며, 이 문서가 그 외부 증거를 면제하지 않는다.
