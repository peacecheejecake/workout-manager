## 다음 실행·검토 계약

1. 위 새 기준 파일의 hash와 표본 hash를 **새 실행 전에** 기록한다. 새 graph build ID·content hash·extract·profile·엔진/adapter 버전과 실행 시각을 별도 결과에 고정한다. 과거 M2-01ay 결과 JSON을 새 실행 결과로 재사용하지 않는다.
2. 동일 82쌍을 제품 `WalkingRouteService`와 `GraphHopperRoutingAdapter`로 실제 실행하고, 가능하면 두 번 실행해 outcome·거리·geometry·태그 대조의 동일성을 확인한다. 경로가 계산됐다는 사실만으로 해당 쌍을 통과시키지 않는다.
3. 구현과 분리된 검토자에게 새 기준 파일·표본·새 결과·필요한 증거만 제공한다. 82쌍의 `match`/`partial`/`mismatch`, 각 층 점수, 실격, 전체 판정을 원래 `acceptanceCriteria`로 다시 계산하고 산술을 검산한다. 이전 결과를 알 수 있다는 한계를 검토 기록에 밝힌다.
4. 새 실행·독립 검토에서 `adequate`가 확인되기 전에는 새 기준의 P8 결과를 `not_executed`로 두었다. 2026-09-27 채점이 완료됐고 기존 `failed` 기록은 별도 역사 결과로 보존한다. 새 기준의 적합을 실제 보행 안전성 증명으로 확대하지 않는다.
